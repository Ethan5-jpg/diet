## 2. 各指标的计算口径

### 2.1 修改版 EAT-Lancet-13

使用蔬菜、水果、不饱和植物油、豆类、坚果、全谷物、鱼类、牛羊肉、猪肉、禽肉、蛋类、乳制品和薯类，共 13 个组件。先计算个人记录期内的日均组件摄入克数，再按每项 0–3 分计分并求和，总分为 0–39。

阈值参考学姐提供的 `supplementary1(1).xlsx`，并用 `diet_score_config(1).py` 交叉核对。乳制品使用 250/500/1000 g/day 分界，未沿用 notebook 中与补充表不一致的阈值。服务器运行第 05 步时使用了 `--confirm-eat-weight-basis`，即按方案接受 `weight_g` 作为摄入克数输入；程序本身不能验证食物生熟重及原料等量是否与参考阈值完全一致。

已实施的适配与修正：

- 缺少可靠添加糖数据，因此删除添加糖组件，原 14 组件版本调整为 13 组件；没有将缺失添加糖按 0 摄入计分。
- BENEFIBER 膳食纤维补充剂不再计入全谷物。
- 带皮水煮土豆归入薯类，修正其此前被归为精制谷物、在新增评分中漏计的问题。
- 经确认，8 个指定植物乳替代产品因缺少配方及原料等量换算数据，不计入 EAT 的食物组件克数。其记录、热量、碳水及 NOVA 分类另行保留。

这 8 个产品的 food_id 为：`1009259`、`1010775`、`1009011`、`1011847`、`1012723`、`1009092`、`1013950`、`1007077`，对应豆奶、杏仁奶、椰奶饮品、大豆奶酪及豆乳冰淇淋等。规则同时核对 food_id 和产品名，不自动扩展到所有植物乳替代品。

因此本指标应称为 **“修改版 EAT-Lancet-13”**，不能表述为完整原版评分。指定产品的排除可能低估豆类、坚果等组件摄入。程序完成分类匹配也不等于所有食品已经过独立人工审核。

### 2.2 已分类食品中的 NOVA4 能量占比

分类顺序为：

1. 用标准化后的食物简称匹配 `supplementary2(1).csv` 的 NOVA 分类；该表已整理为项目配置文件 `diet_adherence_foods.csv`。
2. 对未匹配项，尝试用产品名称与参考表进行精确匹配。
3. 对少量描述明确的单一食物补充分组，记录名称推断依据；不把“面包”“零食”“肉类”等宽泛类别直接当作 NOVA 等级。
4. 三个名称字段均缺失、或仍无充分依据分类的记录，排除出 NOVA 的分子和分母。

日级计算公式：

```text
NOVA4 已分类能量占比（%）
= NOVA4 食品热量 ÷ 全部已分类食品热量 × 100
```

个人指标为有效记录日百分比的均值。若某天没有正值的已分类热量，或已分类记录中存在无法补全的热量，则该天该指标为缺失，不记为 0。

服务器结果：

| 项目 | 数量 |
|---|---:|
| 字典中的食品 ID 总数 | 7,770 |
| 已完成 NOVA 分类的食品 ID | 1,945 |
| 仍未分类、从 NOVA 计算中排除的食品 ID | 5,825 |
| 目标人群与阶段中被排除的饮食记录 | 176,737 |
| 其中三个名称字段全部缺失的记录 | 8,052 |
| 其中其他分类依据不足的记录 | 168,685 |
| 被排除热量占原始全部可计算热量的比例 | 11.8258% |

食品 ID 数量来自字典，记录数和热量比例来自本次筛选后的饮食记录，两者统计层级不同。热量比例只涉及可以计算的热量，不包括无法量化的缺失热量。

**本指标不是完整饮食中 NOVA4 的热量占比。**它反映保留的已分类食品内部构成。排除不确定记录并不能消除选择偏倚，也不代表剩余分类已经全部验证正确。

此次排除仅针对 NOVA 计算，没有物理删除原始 CSV，也没有因此全局删除这些食品记录或参与者。EAT 和碳水指标继续采用各自的数据口径。

### 2.3 碳水供能比

日级计算公式：

```text
碳水供能比（%）
= 当日碳水化合物摄入克数 × 4 ÷ 当日总热量 × 100
```

个人指标为有效记录日百分比的均值，分母为原始饮食记录的总热量，不受 NOVA 分类排除影响。

热量计算优先使用记录中的有效 `calories_kcal`。当其无效或缺失，但碳水、脂肪、蛋白质三个字段均有效时，沿用脚本的 `4×碳水 + 9×脂肪 + 4×蛋白质` 热量补全规则；该补全是估算，非独立测量值。碳水或热量不完整的日记录不生成有效比例；超出 0–100% 的异常比例保留标记，相关参与者不纳入碳水 Z 标准化。

## 3. 标准化与能量校正状态

**三个指标均已完成 Z 标准化，但尚未额外进行残差法能量校正，也尚未在关联模型中调整总能量。**

```text
Z =（个人原始指标 − 该指标有效样本均值）÷ 该指标有效样本标准差
```

样本标准差采用 `ddof=1`。每个指标在各自有效样本内计算标准化参数，参数单独保存。当前未做缩尾处理。

最终字段如下：

| 指标 | 原始值字段 | Z 标准化字段 |
|---|---|---|
| 修改版 EAT-Lancet-13 | `modified_eat_lancet13_raw_0_39` | `modified_eat_lancet13_z` |
| NOVA4 已分类能量占比 | `nova4_classified_energy_pct` | `nova4_classified_energy_pct_z` |
| 碳水供能比 | `carbohydrate_energy_pct` | `carbohydrate_energy_pct_z` |

结果表中旧的 `nova4_energy_pct` 只作为全日总热量分母口径的诊断对照；本次主输出采用上表带 `classified` 的字段。

当前决定先保留这些结果。后续关联分析建议在模型中纳入同一饮食时间窗、质量合格记录的日均总能量及预先确定的其他协变量。该调整尚未执行。比例形式及 Z 标准化不能视为已经充分控制总能量；NOVA 的已分类热量也不能代替原始总能量。
