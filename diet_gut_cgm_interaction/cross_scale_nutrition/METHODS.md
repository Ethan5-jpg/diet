# 共同口径与营养比较方法

## 研究定位与输入

本模块是阅读既有真实结果后的同队列探索性延伸，不是预注册或独立验证。旧中介/整体交互/日级结果均不覆盖。固定2个菌T068（Eubacterium rectale）和T096（Ruthenibacterium lactatiformans），主要结局为日SD，Mean为解释性结局；不重新筛379菌或全部饮食评分。

输入固定为酒精修订版2026-10-11.alcohol.1的完整输出 `revised_20261011T103556_258035Z_9583d5`。核对原运行版本、代码与父代码指纹、配置、AMED来源指纹、保存面板及相关结果表指纹。新程序不导入兄弟目录Python文件、不读取原始CGM/AMED、不修改旧输出。

在开始新分析前，依照旧代码口径重建NOVA4×T068/T096的primary及nutrient_context、SD及Mean共8条模型。检查人日哈希、人数/日数和系数、SE、CI、p与保存结果一致；截图已知primary两菌各3,319人/29,119日，T096营养设定1,887人/13,737日，另将这些已知计数设为固定检查点。T068营养计数按服务器保存表核对，不补造截图未显示值。数值容差rtol=2e−6、atol=2e−9，允许线性代数实现的机器级差异。旧q值不重新计算。

## 暴露、共同样本与权重

主暴露X是每日NOVA4能量/每日总能量×100，再除以10。日级旧主分析用已分类能量分母，本模块在相同F人日另拟合该定义以检查分母影响。输入核对 `total_pct = classified_pct × coverage`；未分类能量并非已证明属于非NOVA4，仍要求至少80%能量已分类，不能据此称因果等能量替换。

F样本同时要求旧primary资格、饮食/CGM日质控、观察来源或日志分类无酒精饮品的酒精口径、两个菌、两个结局及基础协变量完整。每人至少5个完整日，总能量分母NOVA4个人内范围至少10个百分点。所有F模型使用相同人日，包括两个单菌模型、双菌模型、分母比较、Mean条件SD模型；已分类分母敏感性不另换人群或放宽主口径阈值。

N从F人日中再要求碳水、蛋白、纤维密度均完整，随后重新执行5日与总NOVA4范围阈值。N0/N1共享同一个DataFrame，不按模型项各自再次筛选；两者精确人日哈希必须一致。N是F的严格子集或相同集合。F→N0可能同时改变参与者构成和保留日期；它不能被解释成随机删样本效应。每种样本的个人均值在自身实际保留日期重新计算。

W按每个参与者有效日数的倒数加权，使每人总权重为1。B用每人的等日权平均值，一人一行、每人等权。因果目标并未由等权自动确定；这保证比较时不因记录天数不同给参与者不同总权重。窗口平均饮食不是长期习惯，平均每日百分比也不等于跨日能量加权的比值。

菌群使用原始CLR-Z，不在新样本重新标准化。中心与Q25/Q50/Q75固定来自F每人一行的菌分布，在N及各支持性模型继续使用。它们是相对组成指标，不是绝对菌量。

## 两个尺度的模型

用i表示参与者、t表示其有效日期；M表示时间窗菌群状态。

W模型为个人固定效应：

`Y_it = alpha_i + beta_W X_it + sum(theta_Wk X_it M_ik) + C_it gamma_W + sum(M_ik C_it eta_Wk) + error_it`。

程序对Y和全部设计列进行同一加权个人去均值，再进行加权回归。因为M在个人内恒定，`demean(X*M) = (X-mean_i(X))*M`，M主效应和基础协变量主效应被个人固定效应吸收。个人固定效应不排除随日变化的混杂，也不控制未建模的个体特征×饮食斜率差异。

B模型用完全相同人日的参与者平均值：

`mean_i(Y) = intercept + beta_B mean_i(X) + sum(gamma_Mk M_ik) + sum(theta_Bk mean_i(X) M_ik) + mean_i(C) gamma_B + sum(M_ik mean_i(C) eta_Bk) + Z_i delta + error_i`。

Z为年龄、性别、教育、吸烟、睡眠、体力活动、维生素、激素、BMI、CGM设备；分类变量按该样本实际值排序，第一水平为参照。B的SD结局是平均日SD，不是将全部读数合并计算的SD；Mean是等日权平均日Mean。B与W估计不同关联，不能通过符号不同直接断言两菌有不同机制。

C为日能量、来源核验后的酒精、星期（周一参照，6个哑变量）及观察日，并包含这些控制项各自与纳入菌的交互。单菌模型只包含该菌；双菌模型同时包含两菌及上述相关交互，不增加三阶交互。B中无变化的控制块及其冗余菌群乘积一并移除；W中被个人固定效应吸收的常量可移除。其余列秩亏或条件数≥1e8时不自动用广义逆给出结果，记录不可估计。

新W以按人等权为统一比较目标，与旧日级主模型按天等权不同；新B限定共同合格日，与此前使用原整体暴露和更广CGM日期的模型也不同。新结果定位为桥接分析，不反向覆盖原结果。

## 营养和Mean条件分析

N1比N0增加碳水g/1000 kcal（每50单位）、蛋白g/1000 kcal（每25单位）、纤维g/1000 kcal（每5单位），以及每项与两个菌的交互。B用这些密度的日均值；W用日值并做个人去均值。不把未知值填零，不把脂肪等全部闭合营养分量一并放入造成必然共线性，不解释为特定营养替换效应。

SD条件模型在F原模型上增加Mean、Mean平方及其与两菌的交互。B使用个人日Mean均值及该均值平方；W使用每日Mean及每日Mean平方，再去均值。实际编码为 `(Mean-100)/50` 及其平方。相同血糖序列产生Mean和SD，此模型回答给定Mean的条件关联，不是估计不经过Mean的因果直接效应，也不替代主要SD模型。

## 估计、相关差值与区间

设计列先数值缩放，再以满秩SVD估计。W使用按人聚类CR1，有限样本乘子为 `G/(G-1) × (N-1)/(N-G-K_W)`，含被吸收的G个个人截距自由度。B为一人一行OLS，HC1乘子为 `G/(G-K_B)`。两者点态95%CI及p使用t(G−1)。W残差自由度至少100，B至少30；真实样本至少200人。合成验证专用开关仅降低人数至30和B残差自由度至8，不接受SERVER_INPUTS。

同一参与者贡献到多个模型，差值标准误必须包含协方差。对每个模型保留原单位下的参与者估计方程贡献 `I_im = sqrt(c_m) A_m^(-1) s_im`，其中A为加权设计交叉乘积，s为参与者残差得分，c为上述模型的有限样本乘子。按真实参与者身份对齐；某模型没有该参与者时贡献为0。差值方差为 `sum_i (I_i,left - I_i,right)^2`，一般线性对比按对应权重组合贡献。这是联合估计方程的渐近夹心方法，有限样本修正分别沿用各块，并不是将两个标准误平方简单相加。差值使用t(min(G_left,G_right)−1)的近似区间。

完全相同设计/样本的重复估计可能产生差值0及SE0，此时CI为[0,0]、p=1；不把这种确定重复当成独立信息。非零差值但数值退化的SE会被拒绝。F→N0的区间描述不同被选样本估计的差异，不识别营养资料缺失造成的因果影响。

条件饮食斜率在目标菌F分位点求取，双菌模型的另一菌固定在F均值，各控制项保持不变。分位点按本样本描述性锚点处理，CI是给定这些锚点的逐点区间，没有联合覆盖或锚点估计不确定性的额外保证。不存在按高低菌组重新拟合。

## 支持诊断和解释

记录模型条件数、杠杆值，目标交互经其余列残差化后的各参与者信息占比，菌群IQR与尾部人数。主要支持提示为：尾部不足30人、IQR≤0或一人占目标残差信息超过10%。双菌模型另检查目标菌低/高尾部、另一菌位于其F均值±0.25 IQR时各至少30人，提示条件斜率的联合取值支持不足；不是新显著性筛选或删人规则。阈值只在明确合成模式改为8人。

微生物相对组成及共线性可能影响单菌/双菌估计，联合调整保留并不证明物种特异机制。N0→N1衰减不是营养中介；Mean条件SD不是因果直接效应；同队列重叠模型不是独立复现。所有测量按用户确认的同一时间窗解释，不按粪便日期前后再筛选或突出该顺序。

个人记录和样本归属留服务器private/；终端仅输出三屏汇总。代码、源输出和结果指纹均记录，读数校验失败停止，不覆盖或修补历史结果。
