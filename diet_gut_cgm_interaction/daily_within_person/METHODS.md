# 日级个人内分析方法与冻结解释

版本2026-10-11.3（空数据块读取修复，统计设计不变）。研究问题是同一参与者每天相对其个人平均的饮食差异与全天CGM的关联，以及这种个人内关联与既有候选菌群值的交互。T068/T096曾在同队列筛选，本研究是同队列探索性延伸，不是独立验证或新的因果中介。

## 日级数据与人群

使用最终CGM表的每人唯一连接，按participant_id、cohort、research_stage筛选后连接；原始CGM仅保留这个connection_id。协变量表必须有可核实的队列/访视；有CGM连接或设备列时核对一致。基线协变量完整且exclude_diabetes_or_a10不为1进入primary；未知排除标记明确计数，strict_known仅保留等于0。没有协变量记录的人不能作为“未知但允许”纳入。

菌群使用原物种CLR-Z，不以重复日为单位重新标准化。相同人/访视多行不自动挑第一条，不通过人名或文件名猜样本。取样日期优先按sample_name匹配；缺乏样本号时仅允许唯一访视记录，仍称记录日期。多个可疑样本、日期冲突、缺日期或缺身份保持未知，不推定为CGM之前。

可选取样日期表为空或没有目标访视时，只将日期状态记为未知，不中止主分析；必要的人群来源仍必须存在目标访视。仅接受明确的ISO年月日或以该日期起始的时间戳，不把仅有年份、月份或歧义斜杠日期补成某天。

饮食时间沿用本项目既有自报进食时间的操作性解释。带时区偏移的collection_timestamp转为Asia/Jerusalem当地日期，要求与食物collection_date一致。没有时区偏移且没有明确配置naive_timezone的条目不能猜UTC；无法给条目定日时，保守排除该人的本次访视，而非删掉条目后把残余当完整饮食。日期已知的时间/时区冲突剔除该日。该操作不认证逐条时间或完整记餐的真实性。

每日能量使用有效calories_kcal；缺失/无效时仅在碳水、脂肪、蛋白均有效且非负的情况下，沿用上游4/9/4公式补算，记录补算事件数。该公式是现有处理约定，不包含未被宏量营养素字段解释的额外能量。总能量仍有未解决条目则该日不合格。

NOVA4主暴露以已分类能量为分母，并要求已分类能量/总解析能量≥80%。未分类食物不是已知非NOVA4。每10个百分点是当前日级量尺，与昨天原饮食Z的系数不能直接数值比较。纤维为g/1000 kcal，每5单位解释；任何正能量条目纤维缺失则日纤维未知。相同规则用于模型中的酒精以及营养背景的碳水、蛋白；零与缺失区分。

饮食记录要求500–5000 kcal、至少3次有能量进食、首末有能量记录相距≥8小时。进食次数按事件距该次开始超过30分钟才开启下一次，避免零食无限串联。完全相同身份、时间、食物ID和营养值的重复行跨分块识别；受影响日不分析，不擅自将重复认定为输入错误而相加/删除。上述代理会限制适用人群，例如某些短进食窗日不纳入，不能称已识别全部漏报。

## CGM日表型

同连接同时间相同值合并，冲突值或任一无效值使该时间点失效；40–500 mg/dL之外的读数按本项目前期原始CGM合理性规则失效。每个当地日使用等宽15分钟格，每格取有效观测中位数，每个有观测格权重相同。禁止跨缺口插值，不将一日内高频采样区段额外加权。

Mean为有效格均值，SD为有效格样本标准差（ddof=1），CV=100×SD/Mean。它们是本模块从原始记录重新定义的日级指标，未声称与历史IGLU版本逐位复现。个人整体SDw是平均日内SD，与这里单日SD不同。

当地日边界按IANA时区计算，DST日可为23/25小时。格覆盖分母为该日实际预期格数；主要求≥90%，含日两端的最大有效点间隔≤60分钟，四个等时长区段各自格覆盖≥75%。因此无须把“佩戴14天”当作每人的真实观测长度；首尾日同样计算完整日覆盖。严格覆盖改为≥95%、最大间隔≤30分钟，NOVA4相关分析同时要求分类覆盖≥95%。

## 模型、尺度与重复观测

对每个饮食D、菌M、结局Y分别确定完整合格日。每人至少5日且D的个人内范围达到预设门槛（NOVA4 10个百分点；纤维2 g/1000 kcal）；每模型至少200人、吸收固定效应后残差自由度至少100。门槛是研究设计选择，不是官方临床阈值，不因结果显著性调整。

令x为按10个百分点或5 g/1000 kcal缩放的饮食，xw_it=x_it−该模型合格日内个人平均x。m_i=M_i−该组合primary样本参与者等权平均M，敏感性固定沿用此中心。

`Y_it = alpha_i + beta*xw_it + theta*xw_it*m_i + gamma*C_it + eta*(C_it*m_i) + error_it`

C包括每日能量/1000、酒精/10g、星期哑变量和从首次观测CGM日开始的观察日。个人不变的菌群主效应及年龄、性别等主效应由alpha_i吸收，不能在此模型中另外估计菌群主效应；这不等于控制了所有会影响每日饮食斜率的个人因素。

先在模型完整样本内去个人均值，再以SVD求解。数值控制列标准化仅用于改善数值条件，系数和协方差换回原单位。无个人内变化的非目标控制列记录后剔除；目标列无变化、其他秩缺陷或条件数≥1e8则拒绝该项，不自动删除共线目标来强行拟合。

参与者聚类CR1协方差使用参与者残差得分和修正 `G/(G−1) × (N−1)/(N−G−K)`，G为参与者数，N为日数，K为去均值后的有效斜率列数。区间和p使用t分布G−1自由度。等人权敏感性每个日权重1/该人模型合格日数，按相同权重吸收个人截距与计算聚类得分。实现与显式个人哑变量WLS/OLS的聚类协方差作独立数值核对。[statsmodels聚类协方差接口](https://www.statsmodels.org/stable/generated/statsmodels.stats.sandwich_covariance.cov_cluster.html)。

## 预设检验与敏感性

主要结局日SD有2饮食×2菌=4个交互theta，BH输出q_primary4。日Mean/CV为解释性结局；连同日SD全部12项另做BH输出q_all12。每一模型设定保持这两个完整家族，不能筛出显著行后重新校正；失败p在计算分母时按1处理，该行显示p/q未知。两类q不能混称同一阈值，七个设定的84项也不是一次共同的84项BH。

| 设定 | 与primary的区别 |
|---|---|
| strict_known | 仅明确无糖尿病/A10 |
| coverage95 | 更严格CGM完整性；NOVA4或使用NOVA营养控制的模型要求分类覆盖95% |
| days7 | 每模型每人至少7个完整合格日 |
| nutrient_context | 增加当日碳水/蛋白密度、另一饮食暴露及它们与M的乘积；回答营养条件关联，改变估计对象 |
| baseline_slopes | 增加个人内饮食与年龄、BMI、性别和个人平均饮食的交互，检查背景因素/平均饮食对应的斜率差异 |
| equal_person_weight | 每人合计权重相同，检查记录天数不等的影响 |

敏感性分析在各自字段完整性和质量规则下重建样本、个人均值与个人内变化。尤其nutrient_context要求另一饮食及宏量营养素完整，其人数和合格日可能同时变化；与primary的系数差异不能单独归因于增加营养调整，也不是中介解释比例。每项人数、日数、样本哈希和筛选流程均保留。本版本未增加同样本嵌套模型对比；若要专门归因系数变化，须另行完成该对比。

主分析有效参与者的M Q25/Q50/Q75处条件饮食斜率为beta+theta×(Mq−M中心)，区间使用完整协方差；另给Q75−Q25斜率差及区间。分位数来自参与者而非重复天数，不按高低菌分组分别拟合。额外交互的敏感性只报告目标theta，不把其参考类别饮食斜率误标为平均人群斜率。

每项保存样本哈希、样本流、人数/日数、天数和个人内暴露范围、菌群尾部人数、原量尺IQR、条件数、最大杠杆及单人交互列信息份额。IQR零、任一尾部少于30人或单人份额超过10%作支持提示，仍保留可估计检验，不事后排除显著行。within R²是样本内去均值拟合量，不是预测表现。

可行性与样本流另保存质量合格日中饮食暴露、菌群、酒精及任一模型字段缺失的日数。这些原因可以重叠，不能相加为总剔除数；天数/个人内范围筛选在完整字段之后执行。酒精缺失仍为未知，不能因字段缺失而解释为当天未饮酒。若饮食和CGM没有任何同人同日交集，保存零匹配审计、全部84个不可估计行与三屏摘要，不产生显著性结果。

## 解释边界与资料依据

个人固定效应可控制不随观测日变化的个人主效应；漏餐、当天活动/睡眠、反向行为改变及其他时间变化因素仍可能混杂。整天的饮食和整天血糖没有严格的先后顺序；菌群记录也可能晚于CGM，不能由此声称基线预测、饮食干预效应、菌群缓冲机制或因果中介。CV/SD强相关，敏感性重叠样本不构成外部复现。

本模块当前未做滞后因果模型、正式个人间/个人内系数差异检验、功能机制分析或独立验证。原中介路径不能与新交互系数直接相乘，也不由一次交互显著获得证明。

源字段与协议核对：[HPP饮食数据](https://knowledgebase.pheno.ai/datasets/005-diet_logging.html)、[HPP CGM数据](https://knowledgebase.pheno.ai/datasets/017-cgm.html)，2026-10-11；具体输入接口仍以本项目既有代码及真实服务器表头为准。以上日级质量门槛为本模块事前规则，不声称来自官网。
