# Daily Alcohol Revision Implementation Plan

**Goal:** 复用已完成的真实日级面板，以有来源审计的AMED日酒精进行日级交互分析；保留旧运行，结果只能截图回传。

**Architecture:** 在`daily_within_person/alcohol_revision/`建立独立运行入口；依赖且核验父目录2026-10-11.3原代码，不修改父目录模型。读取固定reference面板和AMED日表，核验18:09截图来源SHA256及样本计数后才拟合。每次新建输出，完整个人日记录留在private，终端只显示三屏。

**Tech Stack:** Python 3.8兼容，numpy/pandas/scipy；复用父模块已验证的FE、CR1、BH与对比计算。

18:09截图证据：48,791个QC日全部唯一匹配。仅原值/分类无饮品候选44,687日，允许公式/ABV46,925日。主模型前者已保留NOVA4 3,319人/29,119日，Fiber 2,470人/19,545日；因此主分析无需依赖补算假设。方案在任何新系数或p/q出现之前冻结。

候选方案比较：全样本不调日酒精可保留最多日，但日内变化混杂未处理；允许补算作为主分析多保留一部分日，但增加估算假设。选用原酒精观测/分类无饮品日作为主分析，另两种方案作敏感性。这里的分类零不代表证实没有饮酒，也不等于缺失直接填零。

## 冻结分析家族

保留2暴露×2菌×3结局；主终点4个SD检验qSD4及全部12检验qAll12，各设定分别BH，失败检验保留分母。原6个敏感性使用新的主酒精口径：strict_known、coverage95、days7、nutrient_context、baseline_slopes、equal_person_weight。

新增4个敏感性：alcohol_recovered（可追溯公式/ABV补算并调整）；primary_no_alcohol_control（与主模型相同人日但移除酒精及其菌群交互调整）；recovered_no_alcohol_control（与补算调整模型相同人日但移除酒精调整）；all_days_no_alcohol_control（不以酒精完整性选样且不调酒精）。共11设定×12=132项。q家族不混合，敏感性不作为独立验证或新增发现筛选。

所有设定沿用主样本按人计权的菌群锚点。强制核对两对adjusted/unadjusted实际样本指纹一致（包括结局完整性），不能只比较相同N。分类无饮品、观测、公式、ABV、兜底零、无效原值、缺标签事件分别留审计；主与补算组均排除含兜底零、未解决来源、无效原值、缺标签、源计数异常或事件数不符的日。未知酒精不填零。
