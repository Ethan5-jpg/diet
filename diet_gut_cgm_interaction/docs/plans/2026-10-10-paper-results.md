# Interaction paper results Implementation Plan

**Goal:** 在本模块内提供可阅读的论文图表预览、中英文结果和方法图注，并提供单文件夹上传的服务器正式导出程序。

**Architecture:** `paper_results/` 独立读取已完成的汇总结果；禁止访问参与者输入或重新拟合。截图预览和服务器精度输出有不同来源标记。导出采用现有 Python 科学计算依赖，表格保存 CSV 和可直接阅读/复制的 HTML，图为 PDF/SVG/PNG，每图保留单独 Source Data CSV。

**Tech Stack:** Python 3.8+、pandas、NumPy、Matplotlib；标准库哈希、JSON、HTML和ZIP；原模型完全不变。

用户已明确授权实现，不增加批准步骤、不委派。没有Git仓库，不创建worktree或提交。

## 范围与设计

1. 本地预览只用已转录数值：24项重点主结果、19项原显著扩展、两项NOVA4条件斜率、19项六组q与原始斜率。优先应用17:40及19:10更正，未知p和41项未展示结果不填零；显式标注PREVIEW和截图精度。
2. 图I1为全部24项重点主交互森林图；I2为NOVA4与T068的CV/SDw条件斜率；I3展示原19项全部六组稳定性（不是只选7项）；I4为六组保留扩展的原主模型Q25/Q75条件斜率。图注写明选择标准、样本、单位、逐项CI与校正家族。
3. 正式导出核验旧/新manifest版本、文件哈希、参考运行身份、完整网格、固定84项FDR及204项复现。表格保留全部84主结果、228旧模型、588补充模型、全部条件斜率和新显著组合。补充森林图展示全部60扩展×7设定，按结局和饮食分为可读页面。
4. 所有展示数据从明确列白名单导出，不导出参与者ID/逐人数据、原始输入路径或完整服务器manifest。相对脚本定位上级原outputs和extension_sensitivity输出，结果写入自己的outputs_server新目录；不覆盖已有结果。
5. 提供中英文Results草稿、方法、全部图注、rEDIH定义来源未决项，以及图表目录/阅读页。图表设计参考Nature公开图指南，保留可编辑文本；不声称已通过期刊审查。
6. 核验预览修正值、行数/选择集合、完整导出与图表Source Data、只读输入哈希、迁移路径和错配拒绝。实际查看代表PNG，检查PDF/SVG文本与边界。测试在主模块tests下，预览和上传文件同在paper_results内。
