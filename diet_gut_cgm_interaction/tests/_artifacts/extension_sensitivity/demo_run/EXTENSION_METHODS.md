# 扩展饮食交互的六组敏感性分析

补充版本：2026-10-10.ext1。原拟合引擎保持 2026-10-10.2，不修改原模型代码。此补充在查看主分析结果之后由用户要求开展，属于同队列的事后敏感性分析，不是独立验证，也不能追溯性称为预注册。

## 分析范围

原扩展为 AHEI、AMED、rEDIH、EAT13、Carbohydrate_pct 五项饮食 × 四候选菌 × Mean／CV／SDw，共 60 个组合。全部 60 项均补充敏感性，包括原未通过整体校正的 41 项。原显著 19 项从指定旧运行的 primary、extension、q_all<0.05 冻结，只作为结果追踪集合，不单独缩小 FDR 分母，也不因本次新显著结果而变更集合。

为保持原完整 84 项校正口径，本次连同 hPDI、NOVA4 的 24 项一起重算：84 项主分析 + 六组各 84 项 = 588 次预定拟合。其中扩展结果占 420 行，包括 60 项主分析和新增的 360 项敏感性。它们不是 588 个独立假说或独立发现。

## 六组设定

| 名称 | 定义 |
|---|---|
| strict | 明确糖尿病／A10 合并排除标记阴性者；其他定义同原 strict |
| protocol_same_sample | 药物标记完整同人样本，保留原调整模型 |
| protocol_adjusted | 上述完全相同的人，加入抗生素与 PPI 标记 |
| quadratic | 与该组合主分析相同的人，加入饮食和菌群二次项 |
| covariate_interactions | 与该组合主分析相同的人，加入饮食／菌群分别与年龄、性别和 BMI 的交互 |
| common_all7_sample | 七饮食、四菌、三结局及全部相应协变量完整的统一人群 |

最后一组与原 common_focus_sample 不同：旧分析只要求 hPDI、NOVA4 两饮食共同完整，本次要求七饮食全部完整，可能减少人数。程序要求本组 84 项的样本哈希完全相同，并记录实际 N。不能将该组名称或结果冒充旧两饮食共同样本。

原饮食 Z、菌群 CLR-Z、CGM clean／Z 及单位换算、Model3 协变量、HC3 和残差自由度 t 推断均沿用原方法。中心化、饮食与菌群分位数始终来自对应原主模型样本，不在敏感性样本重新计算原 Z 尺度。二次项模型中的条件斜率定义以及协变量交互的平均斜率定义也沿用 [METHODS.md](METHODS.md)。

## 多重校正与稳定性描述

每个设定使用固定 84 项 BH 校正，字段为 **q_all84**。不可估计和跳过项以 p=1 留在分母，自身 q 留空。原重点 24 项另存 q_focus24，用于核对原结果；它不替代全部 84 项校正。没有按原 19 项重新计算 q。

原显著扩展逐项报告六组的 N、β、逐项 95%CI、q_all84、状态和方向。“六组均保留”必须满足六组全部可估计、交互符号与原主分析相同且各自 q_all84<0.05；任何一组失败／跳过／反向／未通过均不记为六组保留。某一设定新出现的显著组合单独记录，不补进原阳性集合。

“全部六组保留”是描述性稳定性标准，不意味着跨七个设定联合控制了 FDR，也不代表独立复制。显著性改变需要结合效应大小、区间和样本改变理解。逐项区间不是同时区间。负交互表示饮食斜率随菌群取值变化，不能直接解释为低绝对血糖或临床保护。

## 原结果衔接与中止条件

真实运行必须指定原 2026-10-10.2 运行目录。先核对保存的配置、结果文件和原核心代码的指纹，再按模块上级 Data 路径加载输入，逐项要求输入文件哈希与旧 manifest 相同。更换绝对根路径可以，改变文件内容不可以。不会自动改读最新数据或跳过原缺失的输入。

重算之后，核对 84 项原主分析及前五组旧重点敏感性共 120 项，合计 204 项。比较样本哈希、状态、N、系数、标准误、区间、p、主分析整体 q、原重点 q、分位点及部分诊断；数值容差 rtol=1e-7、atol=1e-10。旧两饮食共同样本因定义有意改变不纳入等同性检查。

若输入身份、核心代码或上述复现核对失败，运行标记 FAILED，保存原因和核对表，不写入成功运行指针。结束前再次检查输入、参考文件和当前代码未在运行中变化。可估计性失败仍按原规则保留行和原因；无任何可估计扩展模型时返回 NO_ESTIMABLE_EXTENSION_MODELS。
