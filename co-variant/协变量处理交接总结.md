## 4. 两步处理流程

### 第一步：复制并转换数据源

服务器运行命令：

```bash
cd /home/ec2-user/Desktop/HPP/Data/co-variant
conda activate pheno
bash run_prepare_covariate_sources.sh
```

脚本将指定parquet复制到`raw/`，并把转换结果放入`csv/`。转换时会恢复以下索引字段，避免CSV丢失参与者身份信息：

```text
participant_id
cohort
research_stage
array_index
connection_id（CGM文件）
```

每个文件均检查复制前后的SHA-256；服务器终端结果为`SHA256_MATCH=True`。

### 第二步：生成参与者协变量总表

服务器运行命令：

```bash
cd /home/ec2-user/Desktop/HPP/Data/co-variant
conda activate pheno
bash run_build_covariate_master.sh
```

建表原则：

- `population.csv`中的10k队列定义参与者全集；
- 以`participant_id + cohort`为连接键；
- 所有协变量来源均使用左连接；
- 每名参与者最多一行；
- 有值就写入，没有值保留为空；
- 不在本步骤进行均值、中位数或多重插补；
- 不在本步骤直接删除糖尿病、A10用药或协变量不完整者。

有基线CGM时，以CGM采集日期作为参考日期；没有CGM时，依次从社会人口学、生活方式、人体测量和家族史中选取最早可用日期。年龄由出生年月和参考日期计算。

## 5. 当前协变量和辅助字段

总表包含14个核心协变量：

| 内容 | 字段 | 来源/处理 |
|---|---|---|
| 年龄 | `age_years` | 出生年月与参考日期计算 |
| 性别 | `sex` | `population`标准化 |
| 教育 | `education_level` | 社会人口学分类编码 |
| 吸烟 | `smoking_status` | current/former/never |
| 睡眠 | `sleep_duration_hours_day` | `sleep_hours_daily` |
| 身体活动 | `physical_activity_met_h_day` | 步行、中等和剧烈活动换算 |
| 维生素使用 | `vitamin_use` | ATC前缀`A11*` |
| 激素使用 | `hormone_use` | ATC前缀`G03*`、`H01*`–`H05*` |
| CGM设备 | `cgm_device_type` | 已选定基线CGM connection |
| 酒精摄入 | `alcohol_intake_g_day` | AMED参与者结果；hPDI模型需要 |
| BMI | `bmi` | 人体测量数据 |
| NSAID/阿司匹林 | `nsaid_aspirin_use` | ATC前缀`B01*`、`M01*`、`N02*` |
| 糖尿病家族史 | `family_history_diabetes` | 1型或2型糖尿病家族人数大于0 |
| 心血管家族史 | `family_history_cvd` | 当前使用`sudden_death_family`构建 |

身体活动公式：

```text
(3.3 × 步行天数 × 步行分钟
 + 4.0 × 中等活动天数 × 中等活动分钟
 + 8.0 × 剧烈活动天数 × 剧烈活动分钟) / 60 / 7
```

总表还包含：

- 参与者、参考日期、CGM connection和设备等身份/追踪字段；
- 各来源的原始编码及采集时间，便于审计；
- 3个排除相关字段；
- 6个预设模型完整性标记。

因此后续不必局限于论文预设模型，可以从总表中自行选择协变量。预设完整性标记只是便捷字段，不会限制新的模型设计。

## 6. 排除指标的含义

```text
a10_medication_use
known_diabetes
exclude_diabetes_or_a10
```

这些字段采用三状态：

- `1`：确认符合；
- `0`：有相应来源记录，并确认不符合；
- 空值：来源信息不足，不能判断。

`exclude_diabetes_or_a10=1`表示已知糖尿病或使用A10类降糖药。服务器结果中共有256人满足该排除条件。建表脚本只生成标记，是否排除应在具体模型确定分析样本时执行。不能把空值自动当作`0`。

## 7. 预设模型完整性标记

Model 2共同协变量：年龄、性别、教育、吸烟、睡眠、身体活动、维生素、激素和CGM设备。

- Model 3：在Model 2基础上增加BMI；
- Model 4：在Model 2基础上增加NSAID/阿司匹林、糖尿病家族史和心血管家族史；

- `02_categorical_values.csv`：分类变量各类别人数和比例。

## 11. 建议的下一步

1. 从服务器下载完整的`outputs/data/02_covariate_master.csv`到本地；
2. 使用`participant_id`（并保留`cohort`核验）与已经对齐的diet–CGM分析表合并；
3. 先执行`exclude_diabetes_or_a10 == 1`的研究排除规则，同时单独统计空值；
4. 根据研究问题自行定义协变量集合，不必强制沿用Model 2/3/4；
5. 在每个候选模型中分别报告有效样本量和各字段缺失情况；
6. 身体活动和家族史可能显著缩小完整案例样本，建议同时设计较精简模型和敏感性分析；
7. 完成线性调整模型后，再根据散点图、样条或广义加性模型评估diet–CGM关系是否存在非线性。
