## 直接影响执行的四点

1. **定义复用可以，结果独立性不能假定。**成熟指标不是研究新颖性的主要来源；数据与模型的价值应体现在明确的异质性问题、独立于本轮学习的检验以及可解释的跨域差异。
2. **不把原样本重新分组当作消除了历史接触。**本轮尚未生成参与者历史接触账本。W15逐人／家庭访问状态未知时明确标unknown，再由W18／W22决定允许的验证表述；不凭空排除所有HPP，也不声称完全外部验证。
3. **两种UPF分母是不同变量。**新候选为已知NOVA4能量／全部记录能量，未知NOVA能量保留并给区间；旧报告第16节为已分类分母，第17节已用总能量并做两分母比较。这些定义不能混用，也不能把当前总能量分母称为从未探索。
4. **数值阈值与准入都未冻结。**不依据旧显著性挑UPF／纤维，不因未匹配目录少便认定映射覆盖好；不把W03口腔8291基线证据记录当新研究最终N。
