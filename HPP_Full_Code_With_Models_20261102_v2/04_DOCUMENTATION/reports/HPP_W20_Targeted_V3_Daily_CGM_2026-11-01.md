## 问题、范围与实现

研究问题是菌群特征是否修饰饮食与代谢的**观测关联斜率**。纤维连续暴露参数化为 `u=(纤维密度−训练中位数)/5`，单位为每增加 **5 g/1000 kcal**。保留共享的非线性饮食基函数，以及饮食×年龄/性别项。在固定宿主变量和饮食水平下，菌群特征 `z1` 与 `z0` 的拟合斜率差为 `(z1−z0)'γ`；不解释为个体因果获益。

48 阶段在新拟合前落盘方案并运行四项算法检查。70/30 家庭角色、发现组单层 5 折、确认组不参与选型、55 项 Holm 预算均保持。无新稳定性淘汰阈值、嵌套 CV 或功效前置门槛。UPF 和九结局仍在正式研究范围；本轮先完成纤维×血糖试点及日级分析，尚未推广其余组合，也未启动 W22/W23。

- **v2 ridge**：保留已验收的预测器及其匹配的完整 CLR 主效应 null。
- **残差 CLR 变系数候选**：先用非饮食宿主变量、PC 和完整 CLR 预测连续纤维水平，得到 `a=u−e(C,Z)`；构造 `W=a×中心化CLR`。用匹配 null 的岭平滑器 H 分别残差化 Y 和 W，再拟合 `Y−HY` 对 `W−HW` 的惩罚回归。预测保留惩罚后的幅度。
- **PC5、PC10 有限对照**：W 使用每部位前 5/10 个 PC，其余完整 CLR 主效应背景不变。

所有新候选共用 v2 选择的背景 5 PC/部位、主惩罚 λ=1；交互 λ 固定候选为 0.01/0.1/1/10，按五折平均验证残差校正损失最小选择，平局取更强惩罚。该准则与对应的总 Y 预测损失等价，并不是另外一套独立的斜率检验。保存所有候选，不设“预测增益为正才保留评分”的门槛。

这是明确的正则化残差投影，**不是二元干预 R-learner，也不宣称 Neyman 正交或双重稳健**。训练内 nuisance 残差可能衰减弱信号；`−e(C,Z)×Z` 带来与斜率系数绑定的非线性主效应分量，因此预测变化本身不能单独证明真实斜率修饰。保留完整 CLR 背景并不能自动消除这种工作模型局限。
