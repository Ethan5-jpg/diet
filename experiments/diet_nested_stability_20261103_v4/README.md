# V4：完整 CLR 模型的嵌套家庭验证

2026-11-03 用户授权继续 v3 所指向的预测稳定性研究。独立实验目录；原输入、学长代码和 v1/v2/v3 均只读。

## 问题与预先固定设计

- 比较 histogram gradient boosting、Elastic Net、Ridge；输入为宿主、宿主＋口腔、宿主＋口腔＋肠道。共 9 个模型族。
- 两轮家庭五折：第一轮沿用原 cv_fold；第二轮用种子 20261104 对家庭打乱并轮流分配到五折。70/30 发现/确认角色不变。
- 每个外层训练集内部再做家庭三折；只按内部三折等权平均 MSE 选参数，再在整个外层训练集重拟合，外层验证集只评分。
- 参数网格与 v3 一致：boosting 3 组、Elastic Net 6 组、Ridge 3 组。不根据 v4 外层成绩扩大网格。预计 1080 次内部拟合＋90 次外层重拟合＝1170 次。
- 不做 PCA，不增加新算法。树模型的随机种子沿用 v3（20261103），本轮改变家庭划分来测量划分稳定性。

## 预处理与可比性

每个内、外训练角色内重新拟合：菌种 5% 检出率筛选、零值伪计数、CLR 和尺度、饮食三结点限制立方样条、血糖最短 95% 区间/8 SD 排除/5 SD 缩尾、宿主编码、模型尺度。
菌群和饮食预处理沿用既有“训练角色先拟合，再按结局等条件准入”的顺序；宿主编码与目标标准化使用最终合格训练样本。
从 discovery_v2 原始输入重建，禁止用原五折或 full 的拟合转换代替新折训练。
启动前重现原 fold0 的准入、处理后血糖与双部位 CLR，要求与既有接口一致。

所有 9 个模型使用各外层折相同的双部位支持与准入条件，保证成对比较。
重新拟合阈值可能改变每折人数及目标缩尾值；实际人数单独记录，不强行固定为 v3 的 3343。
主要比较：同输入下树/Elastic Net 对 Ridge、同算法联合输入对口腔、口腔对宿主。
报告每轮完整 OOF R²/MSE/RMSE、成对 MSE 减少率及五折改善数，不直接把新折分数与旧基线 0.07827 相减。

这是此前已参与模型族选择的发现集；嵌套验证隔离本轮参数选择，但不能消除之前的适应性选择。
两轮共享参与者，十个折不是十份独立样本；不据此报告独立重复、显著性或个体因果饮食获益。
确认结局不读取，既有正式确认预算不消耗。
