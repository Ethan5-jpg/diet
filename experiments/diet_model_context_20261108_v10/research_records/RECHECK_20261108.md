# V10 pre-upload recheck

Scope: local code and synthetic inputs only. No native server data were read or
transferred and no native training was started. V6-V9 sources/results are retained.

## Fixed

1. Numeric conversion now supplies an explicit NaN value for nullable pandas
   numeric arrays. Boolean and numeric 0/1 eligibility flags are compared first,
   filled with false for unknown values, then converted to a true Boolean NumPy
   mask. Unknown remains ineligible; new-feature missingness never drops people.
2. Categorical identity grouping explicitly uses observed groups, avoiding unused
   cohort/visit category combinations and the pandas default-change warning.
3. Macro correction uses three nutrient columns, independent of microbial PC
   count. One repeated penalty configuration was removed: **68 pipelines and
   181 candidate settings** remain. No distinct model or penalty was removed.
4. Aggregation now rejects different evaluation populations across repeats even
   when both repeats have the same number of people.
5. Interaction diagnostics distinguish the requested component count from the
   actual modifier width after projection/rank limits.

## Verification

New regression cases exercise nullable Float64, Boolean/Int64 eligibility flags,
missing values, unused categorical identity levels, repeated macro settings and
same-sized but different repeat populations. They run alongside all default
candidate fits, mathematical checks, train/validation isolation, two-repeat
household CV, serialization, resume and shell-dispatch tests.

The exact final status and source hashes are in `local_validation.json`, with the
full synthetic transcript in `local_checks.txt`. The upload manifest is rebuilt
after documentation and validation records are finalized. Local tests do not
replace the native Linux/dependency/data preflight and do not establish R2 gains.
