# 组员 V5 之后的实验总结：V6–V11

更新：2026-11-09。范围为本窗口在组员 V5 后开展的六批模型实验，以及为 V10/V11 准备的数据侦察。**V11 已收到完成截图；本报告不含 V12 或后续尚未完成的实验。**

本地证据来自用户提供的服务器截图、截图转录和已交付的代码/配置。没有下载服务器参与者数据、个体预测、拟合权重或全精度 summary.json，也没有在本地重算真实 HPP 模型。以下区分“代码中确实设计/执行的流程”“截图已展示的结果”和“尚未展示的细分结果”。

## 1. 目前最重要的结论

**整体预测获得了小幅改善。** V6 最均衡融合为 R² **0.114660 / 0.115187**；V11 按“两轮中较低 R²”排序的首位 `positive_combined` 为 **0.130555 / 0.139855**。两轮相对 V6 约增加 **0.015895 / 0.024668**，即约 **1.59 / 2.47 个百分点**。这是跨批开发期的描述比较，不能将全部增量归给某一种算法，更不是饮食×菌群交互独立解释的比例。

**更一致的收益来自营养背景和预测融合。** V10 中，宏量营养输入在 HGB oral 和 Cat balanced 的配对比较中均为两轮正增量；V11 的三条两轮都胜过 V10 的流程，均把旧模型池与新模型池结合。单纯增加模型名称、复杂度或肠道输入，没有普遍提高预测。

**目前没有从这些预测筛查中获得稳定、充分的菌群修饰证据。** 多种显式交互被选为零、或两轮增量方向不一致；一些正点估计出现在较弱的主效应参照上。这个结论限于已试构造与现有评价，不能解释为已正式排除所有生物学修饰。

用户与学长确认后，后续主问题为“**菌群是否修饰饮食—代谢关联**”。总 R² 保留为辅助指标，不再把达到 0.20/0.30 作为唯一硬目标。过去的负结果仍需保留，也不能因改变关注指标而改写为阳性发现。

## 2. 六轮共同的分析对象与评价口径

| 项目 | 本阶段实际口径 |

| 结局 | 人级 `D_Glu`，单位 mg/dL |

这些结果**不是两个暴露×九个结局的 18 个 R² 的平均**，也不是同一个人真实改变饮食后的干预反应。两轮分折不能当成两个人群，更不能把样本数写成 6686。

## 4. 逐轮做了什么、得到了什么

### V6：从单个回归器扩展到树、核和融合

共六组方法、11 条新流程：口腔与口肠 CatBoost、XGBoost、HGB筛选；核主模型；线性、样条、监督压缩交互；预测融合。两条 V4 HGB 只作参考。融合使用当前外层训练家庭的内层 OOF 预测，不能把历史外层预测拿来训练。

`fusion` 两轮为 **0.114660 / 0.115187**，相对 V4 oral HGB 的 **0.110525 / 0.107630** 增加 **+0.004135 / +0.007557**，在 4/5、5/5 个外折改善误差。口腔 CatBoost 为 **0.110465 / 0.111019**，有竞争力；口腔 XGBoost 为 **0.091460 / 0.089819**。核主模型为 **0.092169 / 0.092831**，弱于融合。

线性与样条核交互第一轮微升、第二轮下降；监督交互两轮没有有效非零修正。结论是融合改善了总预测，尚没有可重复的显式修饰增量。

### V7：扩展更多模型家族和表示

加入 LightGBM（host/oral/gut/balanced）、EBM、GAM、Nyström核近似、PLS后接SVR、随机树叶嵌入后线性模型、Hellinger与检出HGB、宿主残差模型、肠道混合专家、低秩FM、加性Boost与PC/gate修正，以及凸/岭堆叠和内层选型。

`ridge_stack` 为 **0.112019 / 0.119128**，第一轮低于 V6，第二轮高于 V6；`convex_blend` 为 **0.111562 / 0.117443**。Hellinger balanced HGB 为 **0.109145 / 0.117441**，检出oral HGB为 **0.109854 / 0.109388**。没有形成两轮共同超越 V6 的总体提升。

这一批保留了重要负结果：PLS-SVR oral 仅 **0.032212 / 0.034998**；balanced 为 **0.009440 / 0.002364**。FM oral 为 **0.017768 / 0.021657**，balanced 为 **−0.131730 / −0.165287**。补充诊断确认，FM oral 的 3/10、balanced 的 9/10 个选中外层拟合触及预算上限，不能把这些数值当成充分优化后FM的上限。

### V8：重组菌群信息，并检验 FM 优化与新饮食背景

增加 NMF 共现因子、PC加筛选菌的全局/局部混合表示、监督PLS、交互导向筛选、UPF上下界、树叶规则+ENet、线性叶树、Huber CatBoost、旋转PC HGB、邻域残差与更充分优化的FM；同时设计组稀疏和NMF饮食乘积修正。NMF因子没有功能注释，不称为代谢通路。

主要融合 `ridge_joint` 为 **0.120803 / 0.121851**，`ridge_wide` 为 **0.120396 / 0.122745**，均比 V6 两轮提高。但 UPF joint 减原输入 wide 为 **+0.000407 / −0.000894**，不支持UPF分支普遍更好。

显示的领先非融合流程包括 `joint_cat_balanced` **0.109047 / 0.111198**、`nmf_cat_balanced` **0.109011 / 0.112568**、`nmf_hgb_oral` **0.108301 / 0.112685**，没有单条非融合路线明显突破。新FM没有已显示拟合警告，但加入FM的凸融合相对不加FM仅 **−0.000000 / +0.000046**；因此上一轮FM预算不足不能解释全部性能差距。

四种显式交互在 40/40 次外层选择中均关闭。`ridge_wide` 对 V6 的条件家庭区间为 **[−0.000679,+0.012151] / [+0.000387,+0.014728]**；一轮跨零，且区间不包含多批模型搜索的不确定性。

### V9：稀疏组成、个体化融合和日级饮食信息

菌群表示包括存在/正丰度拆分、log1p、秩变换、ALR参考对数比、监督几何平衡、稀疏rCLR低秩补全、生态指标及精确菌种ID对齐的口肠结构。学习器还包括Ordered/叶式CatBoost、Tweedie提升树、训练折结局Gaussian变换、残差MLP、深层随机特征网络；融合加入softmax条件门控、树与多项式层。新食物分支只读能量/纤维日级记录，加入波动、分位数、非线性均值、相关性与周末差异。

首位 `convex_wide` **0.119491 / 0.126979**，没有两轮胜过 V8，诊断明确为 **0/64**；本批记录的拟合警告流程数为0。`daily_cat_balanced` **0.108682 / 0.113566**，相对同算法同网格 `ecohybrid_cat_balanced` 增加 **+0.004388 / +0.001642**；oral同类配对反而下降 **−0.001488 / −0.000755**。

三种条件门控没有一种在两轮都超过固定凸融合。四条显式交互共40次选型中39次关闭，唯一活跃的口腔生态修正在第二轮 ΔR²=**−0.000968**。因此本批没有稳定的总体提升或显式修饰预测增益。

### V10：把重点移向营养背景与输入表示

固定加入宏量营养、钠、生活方式与完整背景的梯度比较；分别检验host、oral、balanced，另有gut/口腔分块岭。饮食变体包括宏量＋生活方式、共同三宏量有效日、纤维有效日、边际分布与营养比值。学习器包括HGB、CatBoost、分块岭、样条岭、SVR、ExtraTrees及加性核，同时保留Hurdle与生态混合表示及六条匹配修正。

最均衡 `ridge_diverse` **0.126227 / 0.137266**；相对 V8 wide 增加 **+0.005831 / +0.014521**。`ridge_wide` **0.125175 / 0.136837**，`convex_diverse` **0.122736 / 0.132459**。主要收益不是“只换了一种更复杂的回归器”，而是输入背景与预测多样性的共同变化，需看配对比较。

同类模型加宏量营养：HGB oral **+0.008130 / +0.007903**；Cat balanced **+0.003567 / +0.004918**。full背景中加口腔信息相对host，HGB为 **+0.062685 / +0.073810**。但是Cat balanced相对oral仅 **+0.000124 / −0.000654**，没有普遍的肠道净增益。树模型允许隐式交互，菌群输入增量不能单独拆成主效应或饮食修饰。

共同三宏量日相对full在HGB为 **+0.000461 / +0.000864**，Cat为 **+0.001790 / +0.000985**。钠、生活方式、纤维日或分布/比值的改善依赖模型及轮次，不宜统一宣称有效。

### V11：日级饮食分布、收缩和新旧预测池融合

50条基础流程涵盖11类饮食表示：full/joint、UPF上下界、总体/局部均值收缩、收缩不确定性、均值SE/记录数、同日协方差、随机傅里叶均值、饮食原型占比、投影分位数。日级基底由训练人员拟合，每人总权重相同。加入监督筛选PC、非线性筛菌、线性叶/DART树、后验/Huber CatBoost、Bayesian ridge、ARD、重加权ENet。另有8条残差预测修正、4条显式纤维修正、17条融合。

V11保留V10已完成外层训练家庭中的28成员INNER预测，与62条新基础/修正分支形成combined池。不是把历史OUTER结果拿来训练；旧外层预测在所有新选择和元模型拟合固定后才用于推断/对照。固定V10岭融合重放在服务器完成屏显示最大误差0。

## 6. 数据侦察得到的背景条件

V9后追加了三项只读侦察：数据模式、固定3343人的记录覆盖/日期、营养日完整性。没有新增Y关联或模型拟合。

- 两轮3343人完全重叠；纤维有效日P10/50/90为 **4/8/12日**，能量记录日为 **11/14/14日**。
- 43158个原有能量日的身份/日期锚点均匹配，能量与纤维锚点差异均为0。
- 共同三宏量完整日为 **37676**，至少三共同日者 **3330/3343**；V11启动摘要再次显示同样的日数和人数。新特征不足者保留，按训练角色填补与标记，不换掉原评价人群。
- 碳水、脂肪、蛋白质、钠的奇偶半日记录秩一致性约为 **0.769、0.680、0.749、0.608**；这是同一窗口的一致性描述，不是独立重测可靠性、结局R²或可直接用于误差校正的系数。
- 食物酒精克数覆盖极少（至少三日者26/3343），与问卷酒精频率覆盖不同，不能混用。

## 8. 当前证据的边界

1. V6–V11是同一发现集上的连续开发；多批试验及人工选择带来的适应性不会因每批内部嵌套调参自动消失。
2. 两轮共享人员和家庭。条件家庭损失区间只针对已学到的预测，不覆盖所有模型搜索；单轮区间为正也不是独立确认。
3. 新输入、表示、损失和融合常同时改变，需要具体配对，不能把所有提升归给菌群生物学。
4. 低/零预测增量不能直接证明没有修饰；较高总R²也不能证明有修饰。正式修饰分析还依赖尺度、工作模型、共同支持、时序、混杂与多重比较处理。
5. 不根据结果更换结局、剔除不利人员、松动家庭隔离或事后挑有利分折来追求高R²。
6. 旧截图没有完整展示的单模型分数、区间和拟合细节，必须标为“未展示”，不能推定为零、失败或未运行。

## 10. 给修饰作用窗口的交接要点

本报告先于下一批实验整理。修饰窗口应结合已有阴性筛查，核对其V12方案是否回答“有关联修饰吗”，而不是再次将模型总预测改善当成修饰。

- 主要交互、尺度和纤维对比须在新结果前固定；主要分析与分折敏感性明确区分。
- 主效应背景充分且匹配，保留口/肠及非线性主效应，避免交互代替遗漏的主效应或背景修饰；高维工作模型仍有假设限制。
- 整体交互证据、原量纲效应量/区间、折外预测补充证据和稳定性分别报告；不把非零SD直接当作检验。
- 特征/模块若经过结局筛选或超参选择，普通事后P值不能未经处理直接使用；家庭依赖、多重比较和模拟零假设校准需要核对。
- 当前数据主要是人级均值；不把条件关联异质性改称为个人真实因果饮食反应。若另做日级分析，需重新核对时间匹配和适用样本。
- 可继续开展独立的互补预测方法实验，但它与正式修饰检验是不同任务。保持已冻结数据、评价口径及清晰的资源预算，所有新结果仍按发现期探索解释。
