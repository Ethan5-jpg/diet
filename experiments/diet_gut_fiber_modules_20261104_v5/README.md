# Gut fiber interaction in discovery households

Use a new sibling of v4 under the collaborator handoff experiments directory. All observed data, fitted rules, stage notes, diagnostics and predictions stay in TRE. Run audit_v4.py to verify paired HGB gains from saved predictions. The W14 CGM operational contract and candidate mapping define D_Glu as the equal-day visit mean of qualified daily CGM glucose (mg/dL); diet and CGM windows may differ.

A uses the v1 host design, oral/gut PC1–5 as unpenalized background and standardized dual-site CLR main effects (mean-loss ridge lambda 1). B adds fiber × gut PC1–10. C substitutes gut modules. Module scores are linear combinations of the shared CLR background; add no separate main effects. The two v4 outer allocations and their nested family three-fold inner allocations are fixed. Refit all preprocessing on each training role, select interaction ridge by equal-fold MSE with stronger-shrinkage tie break, and replay original-fold A and fixed lambda 0.1 B against v1. Report repeats separately.

Use frozen v4 microbiome preprocessing: retain >=5% detected, replace zeros by half the positive training 1st percentile for each retained taxon, CLR over that reference set, omit near-constant coordinates, center and scale. Apply the same rule to new samples; all-zero retained abundance is unsupported. PCA uses training supported samples per site, centers standardized CLR, divides PC scores by their training SD. Combine PCs with raw interaction coefficients (interaction design scaling already inverted by v1), undo PCA scale, CLR scale, centering and CLR reference subtraction. Test reconstruction against raw zero-replaced logs per fold. A truly unselected taxon has no entry; a reference-only taxon can still enter through the geometric mean.

For C cluster gut species columns only, using signed proportionality 2cov/(var1+var2) of unscaled training CLR, average linkage on one minus this value, single distance cut 0.5, minimum size three. Score each module by the arithmetic mean of its members' training-standardized CLR values. Scores have a fixed positive orientation. Unclustered species remain in A/B/C main effects. Save memberships and weights privately; compare best member Jaccard across other folds. No sweep of cuts.

At 10 and 15 g/1000 kcal assess held-out households within ±1, separately in each training-score quartile; <10 households at either endpoint flags thin support. Within each round compute OOF residual slope calibration on training-SD scores using the v1 regression and family CR1 conditional intervals. Score dispersion measures predicted modification, not treatment benefit. See config.json for gates; gates are descriptive discovery decisions. Keep confirmation sealed.

Run test_features.py locally and in TRE before the private run. See run.py for staged execution. Source-only GitHub sync.
