# Experiment 2 / V6：历史比例核算与菌群交互模型扩展（扩充检查版）

先核算历史结果，再在原来的发现组做新的饮食×菌群交互实验。V6 单独上传本文件夹即可；仍需要服务器上原有的历史数据、V11 注册和旧的预处理代码。无需重新上传 V1–V5，无需删除旧结果。

## 这一轮算什么

同一批人、同一个 D_Glu 人均血糖结局、同一套家庭划分：

```
M0 = 饮食/宿主/背景 + 菌群主效应（禁止饮食×菌群）
M1 = 完全相同的 M0 + 饮食×菌群交互修正
ΔR² = R²(M1) - R²(M0)
相对交互预测增益(%) = 100 × ΔR² / R²(M1)
相对基线改善(%)     = 100 × ΔR² / R²(M0)
```

两个百分比都会输出，主排序用第一个。它们是配对预测分数的比值，不能称为“菌群占饮食因果总效应的百分比”。没有把之前 V11 的 0.13 直接当分母；只有同一个配对对照的分数才能相除。负结果完整保留。完整 R² 为负或接近零时不提供正贡献排序；分母区间触零时不提供比例区间，并标记原因。

## 实验范围

- 36 组 PC 交互：口腔、肠道、两者联合；PC5/10/20/40 岭交互；PC10/20 的原两列饮食基（线性及冻结非线性基）；PC10/20 的监督 PLS、Elastic Net、RBF 非线性菌群修饰。
- 新增 18 组菌群组成交互：每部位仅在训练期选最多 16 个常见高变菌，分别用 CLR 坐标、所有两菌 log-ratio、存在/丰度两部分表示，各配岭和 Elastic Net。
- 新增 6 组树变系数交互：PC10/20 输入浅树，寻找多菌背景下饮食斜率的阈值变化；树只用菌群划分，修正仍是饮食乘以菌群函数。
- 新增 6 组曲线张量交互：原冻结的两列饮食基乘 PC5/10 的训练分位点分段线性基，覆盖更灵活的非线性菌群修饰。
- 2 组原方法对照：纤维×肠道 Shannon、纤维×三菌固定评分。三菌名称严格匹配，缺失/歧义会停止，不补成零。评分沿用 V3 定义。
- 总计 68 组单独交互，每组 3 个罚项，共 204 个非零设置；每组内都另有零交互选项。
- 5 个内折选择流程：全体、肠道、口腔、联合部位、原始 38 组对照。
- 5 个组合流程：四类算法平衡组合、肠道组合、线性模型组合、菌群组成组合、全体表示组合。内折选择是否启用及缩放。
- 最终 78 条输出路线，每条都跑原来的 2 次×5 折家庭外层评估。两次重复用的是同一批人。

肠道 PC10 是历史探索中较好的方向，因此这轮保留并扩展其附近的维数和模型。共同基线同时含所有候选的微生物主效应，包括 RBF 的精确同一映射，避免给某一条路线较弱的主效应对照。基线的两个树模型设置只在内折选择。所有超参数、零修正及组合选择都不看外层结局。

新增组成特征和张量边际基也进入同一共同基线。树修正使用的 PC 全部在基线菌群非线性块中。文献依据、与原论文算法的区别和这轮不纳入的方法见 `LITERATURE_AND_EXPANSION.md`。旧 45 路上传包已另存备份；当前文件夹和新的扩充版压缩包包含全部 78 路。新运行标识包含 `expanded`，不会与原 45 路检查点拼接。
