# Experiment 2 v2 · 人均血糖的菌群修饰效应

本版本使用人均纤维密度和人均 D_Glu，估计纤维密度同样相差 5 g/1,000 kcal 时，不同菌群特征对应的血糖关联相差多少。程序逐折复用 V11 的 **3,343 人、3,059 个家庭、两套家庭五折、训练折表型处理和原留出结局**。两轮使用同一发现集。 [V11 结果](https://github.com/Ethan5-jpg/diet/blob/main/experiments/diet_model_distribution_20261109_v11/research_records/2026-11-09_172529_complete/terminal_transcription.txt)

## 服务器结果

2026 年 11 月 12 日，主分析、纤维分段分析和年龄、性别基线敏感性分析均完成两轮。肠道 Shannon 的主分析修饰差为 **+0.649 / +0.504 mg/dL**。相同指标的留出预测 ΔR² 为 **−0.000283 / +0.000326**。 [结果报告](research_records/2026-11-12_server_run/RESULTS.md) · [终端汇总转录](research_records/2026-11-12_server_run/terminal_transcription.txt)

## 同一批人回答两个问题

| 输出 | 问题 | 实验 |
| --- | --- | --- |
| `EXP2_V2_EFFECT` | 关联相差多少 mg/dL | 固定纤维 10→15 g/1,000 kcal，比较连续菌群指标第 75 与第 25 百分位对应的血糖关联差。肠道 Shannon 为优先解释指标，另报告口腔 Shannon 及口腔、肠道优势度。 |
| `EXP2_V2_RAW_EFFECT` | 修饰估计对原表型处理有多敏感 | 同一批人和同一个关联设计，换成未经 V11 折内处理的原始人均 D_Glu。 |
| `EXP2_V2_DOSE_SHAPE` | 肠道 Shannon 修饰是否随纤维水平改变 | 固定 12.5 g/1,000 kcal 为转折点，分别报告 10→12.5、12.5→15 和 10→15 的修饰差，单位 mg/dL。 |
| `EXP2_V2_PREDICT` | 交互多解释了多少血糖波动 | 同一已拟合基线加指定的纤维 × 菌群交互，计算两套模型在同一批留出家庭的配对 ΔR²。 |
| `EXP2_V2_STABILITY` | 学到的修饰差异对换折有多敏感 | 比较同一批人在两套家庭划分上得到的 10→15 交互预测差。报告两轮各自的标准差和跨轮相关。 |
| `EXP2_V2_HOST_PREDICT` | 基线允许年龄、性别与菌群交互后，纤维交互还有多少增量 | 可选重跑。使用相同人群、结局、家庭划分和候选网格，对肠道 Shannon 与两部位联合学习两条路线做配对比较。 |

**固定指标分析。** 四个指标分别进入单独的连续交互模型，避免将高度相关的 Shannon 和优势度同时作为待解释交互。各外折用训练角色拟合的主效应特征构造固定背景，关联回归允许各折背景系数不同，并估计一个共享的交互系数。预测分数使用独立的训练与留出流程。区间按家庭聚类 CR1，另给四个指标的 Bonferroni 家族 95% 区间。输出核对两个菌群尾部内的纤维密度第 5 至第 95 百分位是否覆盖 10→15。覆盖诊断用于解释估计，主评分沿用全部冻结人员。该检查描述两个尾部的边际摄入范围。输出还计数每个尾部内距离 10 和 15 不超过 1 g/1,000 kcal 的人数。结果是固定工作模型下的发现集关联。区间以已定特征、折内表型处理和样本分位数为条件，未包含这些步骤的估计误差。V12 的相关结果已知，换折用于敏感性核对。 [V12 结果](https://github.com/Ethan5-jpg/diet/blob/main/experiments/diet_effect_modification_20261109_v12/research_records/V12_FINAL_SUMMARY_20261109.md)

**配对预测。** 非线性梯度提升树基线有两块输入，一块是宿主和饮食，一块是两部位的 CLR 主成分和生态指标。树路径只允许使用同一块。完整模型在同一拟合基线上加交互。四个固定指标路线分别估计线性交互。三条学习路线分别以口腔、肠道、两部位联合为输入，在当前训练家庭内筛选 5 或 12 个菌群方向，比较线性和样条纤维基底。每个外折的树设置、修正形状和惩罚由内折决定，修正候选包含零。另报告内折从七个交互路线池选择的 `selector`，共 33 个不同设置含零。训练残差的树拟合在当前训练角色内再次按家庭分折。 `delta_R2` 的区间以外折预测固定，配对重抽 1,999 次家庭。所有折都选择零修正时，区间 [0,0] 对应两套预测逐人相同。

**固定转折点。** 在原关联背景上控制纤维的线性项和在 12.5 处的折线项。两项同时与连续肠道 Shannon 相乘，允许两段的修饰斜率不同。转折点取 10 和 15 的中点，使用 V11 原留出结局。除两段和全区间外，`above_minus_below` 直接估计两段等宽剂量的修饰差之差。对比共享同一次拟合，家庭 CR1 区间为逐项 95%，用于探索剂量形状。输出计数在两个 Shannon 尾部内距离转折点不超过 1 g/1,000 kcal 的人数。解读时同时看 `EXP2_V2_EFFECT` 中的两端摄入范围。

**年龄和性别基线。** 可选运行允许两个主效应列进入菌群块，宿主饮食块保留全部原输入。基线在年龄和性别固定时，仍限制饮食与菌群直接交互。每个外折在这个基线上重新选设置，再比较该基线与在其上添加纤维 × 菌群交互的模型。 `EXP2_V2_HOST_STABILITY` 对同一批人的预测差做换折对照。

## 上传和运行

服务器上的目录结构为 `<交接包>/experiment2_Effect_Modification/v2`。脚本沿用此前核对成功的 V12 解释器。上传后，从服务器交接包根目录执行以下命令。

```bash
cd experiment2_Effect_Modification/v2 &&
bash server_run.sh --preflight &&
bash server_run.sh --threads 2
```

在同一个目录运行年龄和性别基线敏感性。

```bash
bash server_run.sh --host-sensitivity --threads 2
```

回传从 `EXP2_V2_EFFECT` 到 `EXP2_V2_COMPLETE` 的主结果。可选运行回传 `EXP2_V2_HOST_PREDICT` 和 `EXP2_V2_HOST_STABILITY`。若出现 `EXP2_V2_STOP`，回传该行。两种模式均可加 `--repeat 0` 单独运行主轮。先看肠道 Shannon 的估计、家族区间及饮食范围覆盖，再读固定路线和学习路线的两轮 ΔR²。历史 V11 总 R² 作为参照单独显示。

预检使用生成数据。正式入口逐折核对旧模型使用的评估行和处理后 D_Glu，服务器实际结果由正式运行产生。

本地预检覆盖已知线性和分段交互、无修饰、训练留出隔离，以及新增基线中年龄和菌群可以交互、固定年龄时纤维和菌群不能交互的预测检查。

使用 3,343 人、3,059 个家庭的生成数据，主流程和年龄性别基线各完成两轮家庭五折。带已知交互的数据在两种基线下都找回了修饰信号。无修饰的数据完成主流程第一轮，肠道 Shannon 关联区间覆盖零，配对预测未见明确增益。
