# V20 校准饮食基准上的七类菌群交互与剩余掉分

原 18 组沿用锁定档案。扩展分析在每个结局和每个外折共享 A、家庭、结局清洗、饮食字典与计分分母。B 比较既有参考版与 V19 分域校准版。分域幅度、内层家庭选择与回退均沿用 V18/V19。

每个 B 的对照包括关交互、整体饮食半幅交互、七类各自的半幅菌群交互。各条件交互均控制完整整体饮食主效应。以同一 B 训练残差拟合饮食类别 × 肠道 PC1/2，移除 A 和完整饮食主效应设计的线性成分，交互岭惩罚为 1，应用幅度 0.25。训练和计分均保留全部已登记表征。两套新的发现组家庭五折种子为 20262611 与 20262643，启动时回放 V19 的参考和校准整体半幅（包括 A/B/C）。

按类别和结局域报告 B−A、C−B、C−A、持续和严重掉分，以及稳定交互候选。严重掉分要求两套均 ≤−0.10 个 R² 百分点。稳定交互增益需要两套 C−B≥+0.10、C−A>0，并且每套至少三折交互正向。按每个领域至少五个共同表征的规则等权汇总各域内 C−B 中位数。全矩阵 Holm 用于描述。逐项报告 V18 已登记组合在旧和校准 B 下的发现组方向，独立假设和判定方案保持归档。

对于校准版每个 C 的两套均发生 C−A<0 的表征，按关交互 B−A 的两套方向划分：两套 B 已经掉分、两套 B 均未掉分，以及 B 在两套方向混合。另计 B 两套都掉分但 C 两套都恢复非负的表征。对关交互后两套仍掉分的表征，用 V18 的对齐项 2Σ(Y−A)(B−A) 区分两套对齐项均为正但幅度代价更大、两套对齐项非正和混合三类。对两套 B 均未掉分、加交互后两套均掉分的表征，也报告交互对齐项 2Σ(Y−B)(C−B) 的方向。完整计数按结局域留存。

两套分折仍于同一发现队列重复。当轮稳定性用于比较和安排验证。预留结局不参与。
