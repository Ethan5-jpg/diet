# Full_pheno_v3 · 固定血糖分支与全表型交互融合

本轮沿用纤维和 UPF × 九个表型的发现组五折。所有流程在纤维→平均血糖这一组使用原 `v1_fusion`。跑分前后核对 v1 样本及折计数，逐组复现 v2 原 54 个设置的 off/on R² 和 ΔR²。全组仍使用 v1 无交互主效应预测作为配对基线。

## 起点

v2 的发现组诊断中，纤维→平均血糖的 `v1_fusion` 为 +0.8882 个 R² 百分点、占完整模型 R² 的 13.49%。其余组的四个最高点估计如下。

| 饮食→表型 | 逐组最佳 ΔR²（百分点） | 达到 +0.10 的 v2 设置数 |
|---|---:|---:|
| UPF→总脂肪 | +0.1798 | 4 |
| 纤维→肝脏超声声速 | +0.1363 | 1 |
| 纤维→内脏脂肪 | +0.1215 | 3 |
| UPF→肝脏超声声速 | +0.1060 | 1 |

其余 17 组的所有 v2 设置，校正后区间下限均未高于零。这个筛查用于决定开发方向。UPF→总脂肪优先比较收缩不同的肠道 PC，脂肪和肝脏表型测试各自的参数共享。三菌及 Shannon 的旧剂量诊断在 18 组均有覆盖。

## 候选与流程

固定交互库有 202 个设置。包括 v2 的 54 个、在原表示上增加的 64 个岭设置、缩窄 PC 或区分口腔/肠道生态指标的 48 个设置，以及 36 个脂肪或肝脏同域共享设置。共享的系数由同一饮食下各表型标准化训练残差等权拟合，可直接使用或再向单个表型拟合调整。血糖使用可应用的 166 个候选。旧的四个跨表型联合候选仍按 v2 口径重建。

| 流程 | 其余 17 组的交互修正 |
|---|---|
| `fixed_pc5` | 固定使用 v2 的肠道 PC5 线性岭回归，惩罚 1 |
| `select` | 内层配对误差最小的单一候选，含零修正 |
| `select_guarded` | 内层 ΔR² 至少 +0.05 个百分点且 4 折中至少 3 折误差下降，再挑单一候选 |
| `mean_top3` | 内层总体为正且至少 3/4 折为正的候选，按菌群表示取最多三条等权融合 |
| `blend` | 用内层误差从不同表示中筛最多八条，学习非负加权融合 |
| `blend_guarded` | 主流程。候选缩权后与最终融合都要求总体至少 +0.05 个百分点且至少 3/4 折为正 |
| `domain_blend` | 同一饮食和表型域内共享带门槛的融合权重，按各表型内层 SST 归一化误差并等权 |
| `domain_partial` | 同域融合与各自带门槛的融合各占一半 |

融合仅使用各候选相对无交互基线的预测修正量。权重非负，总和最多为 1。最终带门槛的融合未通过内层检查时，改用已过门槛的最佳单路缩权修正。没有达标候选时使用零修正。保留共同主效应和同一批外层留出预测者，对照关闭的是整个饮食×菌群修正。

## 家庭划分和区间

外层沿用 v1/v2 五折。每一外折内，其余四折轮流留出给内层选模。内层按训练家庭重拟合 CLR/PCA、结局处理、预测特征缩放和模型。UPF 特征使用该外折预先在外层训练家庭里拟合的概率校准缓存，内层权重是在这个固定暴露表示下学习的。最外层留出家庭的结局不参与选择模型、权重或参数。血糖固定分支使用原外层的所有变换及系数估计规则。

评分对每组统计 ΔR²、占比、正向折数，也分解交互修正与无交互残差的对齐项和修正平方项。两项相减为 ΔR²。家庭同步重抽样 9,999 次，所有流程共用同一抽样权重。为了比较融合有没有价值，同时给出各流程相对固定 PC5 的配对差值，以及主融合相对单模型选择的配对差值。区间对全部流程和配对差值使用同一最大偏差校正，条件是已经拟合的折外预测。占比只在两臂 R² 均通过原分母稳定性检查时输出。

同批人诊断另外用固定 PC5，逐表型仅在纤维和 UPF 都有留出预测的交集上评分。这样可观察两种饮食的差异在相同评分人群上是否仍存在。每种饮食继续使用各自原来的训练样本和已拟合预测。

旧 v2 已用于设计，因此 v3 仍是发现组开发。固定候选库的逐组峰值只作探索。流程比较的成绩来自内外层分开拟合后的真实外层预测。正向组数、≥0.10 / ≥0.25 个百分点组数、中位数和下降组数分别显示。用于本轮比较的门槛以 R² 百分点表示。预留家庭结局不参与本轮。

## 上传与运行

把整个 `Full_pheno_v3` 上传到服务器 `Full_pheno`，与 `v1` 和 `Full_pheno_v2` 同级。正式运行读取两版已完成的 `runs/TRE_ONLY/discovery-1` 汇总和原发现组输入。使用原 V12 的固定 Python 环境。

~~~bash
cd /home/ec2-user/studies/diet_gut_cgm_v2/multisystem_project_20261021/collaborator_handoff_20261102_v1/experiment2_Effect_Modification/Full_pheno/Full_pheno_v3 &&
bash server_run.sh --preflight &&
bash server_run.sh --threads 2
~~~

看到 `FULL_PHENO_V3_COMPLETE` 后，可用 `bash server_run.sh --report` 重读摘要。默认在 v3 的 `runs/TRE_ONLY/discovery-1` 写入以下汇总。

| 文件 | 内容 |
|---|---|
| `summary.json` | 固定血糖分支结果、17 组整体排名、配对评分和区间 |
| `workflow_scores.csv` | 18 组 × 8 个流程的 off/on R²、ΔR²、校正区间、占比和修正分解 |
| `workflow_comparisons.csv` | 相对固定 PC5 和逐组选模的配对 ΔR² 差值 |
| `library_screen.csv` | 其余 17 组适用的固定候选点估计 |
| `fold_choices.csv` | 逐折选中的候选、融合权重和零修正回退 |
| `diet_overlap.csv` | 九个表型在两种饮食共有的留出者中的固定 PC5 增益 |

输出均为组级或折级汇总。重复运行校验并复用相同设置的已完成结果，可用 `--run-id` 另起一轮。
