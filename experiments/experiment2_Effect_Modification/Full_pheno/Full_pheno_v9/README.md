# Full Pheno v9 饮食特征扩展与负向组合处理

从现有发现组日记录、食物事件、营养日级质控和 NOVA 分类中构建营养素密度、来源纤维、食物类能量占比、加工分级、记录日间模式及用餐情境。纳入至少三天且覆盖一半有效日期的特征，每列独立核对。食物事件热量和纤维逐日与登记总量配平，NOVA 未分类能量独立记录。时段只采用通过时钟质控的记录，外食份额只采用分类覆盖充分的日期。保存每列覆盖、非零计数及各训练折最终纳入的列数。训练折估计截尾点和归一化参数，缺失在中心化后取零，沿用原样本分母。

比较各组作为新增饮食主效应、全部组一起加入及其余量与肠道 PC2 的补充交互。另一套流程基于训练家庭的内层留出预测筛选特征组，对反复负向的完整饮食或单独交互降到半幅或关闭。也对照在 v8 五套划分内始终为负的组合按固定规则停用。停用组合仍以原分母计分，关闭后的增量可为零。训练适应流程保留纤维→血糖原锚点和已冻结的纤维→肝脏黏度候选，并核对 v8 在原测试折的复现。

两套新划分使用固定候选，折内重估适应规则及预处理。按家庭同步重抽 9,999 次，在各划分的比较集合内校正。所有结局均来自既有发现组，预留确认家庭继续封存。
