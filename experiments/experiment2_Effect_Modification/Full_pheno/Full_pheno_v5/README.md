# Full_pheno_v5 · 饮食 × 菌群修饰效应

## v4 结果与本轮对照

两种饮食暴露是纤维密度和超加工食品（UPF），结局包括平均 CGM 血糖、总脂肪、内脏脂肪及六项肝脏指标。每种饮食和每个结局各成一组，共 18 组。

| v4 流程 | 正向组数（18 组）| 其余 17 组的正向 / ≥0.10 pp / ≤−0.10 pp | 其余 17 组中最大 ΔR² |
|---|---:|---:|---:|
| 缩半 PC5（`pc5_half`） | 10 | 9 / 1 / 0 | +0.1053 pp |
| 原固定 PC5（`v3_fixed_pc5`） | 9 | 8 / 1 / 0 | +0.1707 pp |
| 逐组最大化最弱内折（`new_block_maximin`） | 4 | 3 / 2 / 6 | +0.1806 pp |

纤维→平均血糖沿用 `v1_fusion`，ΔR² 为 +0.8882 pp，完整模型 R² 从 0.05695 升至 0.06584，交互占完整模型 R² 的 13.49%。v4 的同时 95% 区间为 [−0.2919, +2.0684] pp。这是发现组结果。

v4 的其余 17 组里，逐组筛选的最高点估计是 UPF→肝脏黏度 +0.2563 pp。该组合的无饮食、关交互 R² 分别约为 0.01385、0.00975。即使加上这次筛到的交互增量，其完整模型 R² 仍低于无饮食模型。固定 PC5 的 UPF→总脂肪增量为 +0.1707 pp，通过分母核查的全模型占比为 1.77%。其余 17 组中，各工作流经过多重校正后均无正向增量支持，也没有工作流显著优于原固定 PC5。

## v5 设计

沿用原家庭划分和每组的纳入规则，固定纤维→平均血糖的 `v1_fusion`。其余组合重点比较相同关交互预测下的增量。应用于所有组合的是同一套工作流，内层自适应流程可以对不同组合给不同补充权重。

- **调节 PC5 交互幅度**。复核 v4 的缩半 PC5、原固定 PC5 及 `new_block_maximin`，同时试 0.35、0.65、0.80 倍 PC5 修正。
- **让饮食剂量和菌群水平弯曲**。新增 108 个设置覆盖口腔 Shannon、肠道 Shannon、三菌总评分、肠道 PC2、肠道 PC5、口腔与肠道各前两项主成分。每项分别试剂量弯曲、菌群指标弯曲和两者同时弯曲。对同一主效应基线和已加半幅 PC5 的预测分别尝试补充交互，用两档岭惩罚和一档稳健加权岭回归。节点和标准化参数由训练折估计。拟合将交互乘积对主效应和额外剂量、菌群单边基函数做训练折投影，再拟合剩余交互。张量积方法的一般背景见 [Wood, 2006](https://doi.org/10.1111/j.1541-0420.2006.00574.x)。
- **融合和借力**。固定测试少量口腔 Shannon 曲线和肠道 PC2 剂量曲线；自适应测试精简候选集 `add_core`、新张量交互集、要求四个内折都受益的方案、同种饮食共用一个补充候选（按结局领域等权）、相同领域共用一个候选，以及领域共用但由本组复核的方案。
- **限制自适应权重**。补充方案与半幅 PC5 做凸组合，补充一侧权重上限 0.50。默认要求内层合并 ΔR² 相对半幅 PC5 至少增加 0.02 个百分点、至少三个内折改善、合并的交互增量为正，而且相对关交互的正向折数没有下降。未达到条件时回到半幅 PC5。同领域和同饮食共享流程在汇总的内层表现上选择方向。`domain_veto` 会额外检查目标组合。

共 422 个固定设置，包括 314 个 v4 设置和 108 个新设置。14 条工作流与 18 组交叉评分。任何参数、方案和权重选择只在对应外折的训练家庭内完成。与 v4 一致，UPF 暴露校准使用外折训练信息并在其内层复用。

## 指标

在同一组、同一批折外人员上，记 (A) 为移除所考察饮食项及该饮食与年龄、性别交互后的 (R²)，(B) 为保留这些项、关闭饮食×菌群交互的 (R²)，(C) 为打开饮食×菌群交互的 (R²)。三者都保留共同的宿主、能量与菌群主效应背景。预测量的计算为

| 输出 | 计算 |
|---|---|
| `delta_pp` | 100 × (C − B)，单位为 R² 百分点 |
| `total_diet_pp` | 100 × (C − A)，单位为 R² 百分点 |
| `full_share_pct` | 100 × (C − B) / C |
| `diet_share_pct` | 100 × (C − B) / (C − A) |

用于比较覆盖面的绝对门槛是 +0.10 pp，同时记录 ≥+0.25 pp 和 ≤−0.10 pp 的组数。以半幅 PC5 为对照，本轮希望同一工作流在其余 17 组中至少有 2 组达到 +0.10 pp，至少 9 组为正，且没有组下降 0.10 pp 或更多。再用同时区间判断这些点估计有多少统计支持。

两种占比均须通过分母核查。全模型口径要求关交互与开交互的 R² 在点估计及全部家庭重抽样中都大于数值下限 1e−8。饮食口径要求 C−A 在点估计及全部重抽样中都至少 +0.10 pp。CSV 同时保留满足数值下限的比例点估计，分母核查未通过时正文使用 `NA`。这些量描述模型的折外预测增量。

各组共享 9,999 次家庭重抽样。在 18 组上同时校正交互增量、与半幅 PC5 的配对差，以及饮食总预测增量。区间基于已拟合的折外预测。逐组最大值和固定设置的覆盖面排行供发现组筛选，需用独立数据确认。

## 服务器运行

把整个 `Full_pheno_v5` 文件夹上传至原有 `Full_pheno` 下。v5 复用 v1–v4 的代码及已经完成的 v4 发现组结果，并核对 v4 结果与当前输入快照。默认读取 v4 的 `discovery-1`。v4 如使用了自定义运行名，执行正式命令时加上 `--v4-run-id 实际运行名`。

```bash
cd /home/ec2-user/studies/diet_gut_cgm_v2/multisystem_project_20261021/collaborator_handoff_20261102_v1/experiment2_Effect_Modification/Full_pheno/Full_pheno_v5 &&
bash server_run.sh --preflight &&
bash server_run.sh --threads 2
```

```bash
bash server_run.sh --report
```

结果默认保存到 `runs/TRE_ONLY/discovery-1/`。终端报告的 `WORKFLOWS` 汇总工作流覆盖面，`PRIMARY_PAIRS` 列出 `add_core` 在 18 组的配对结果，`CHECKED_SHARE_PEAK` 给出分母合格且 ΔR² 达到门槛的占比最高组。四个 CSV 保留工作流计分、与半幅 PC5 的配对差、候选设置的描述性计分及每个外折的实际权重。
