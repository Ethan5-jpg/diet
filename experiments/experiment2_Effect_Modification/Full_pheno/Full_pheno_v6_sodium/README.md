# Full Pheno v6 · 钠密度敏感性复核

这是同一发现组的后续探索，针对总脂肪和内脏脂肪。钠密度按钠记录单独确定覆盖，不要求同时有可用的蛋白质、碳水和脂肪记录。比较至少三天且覆盖有效能量日 80% 或 50% 的两种规则。每种规则里，在相同人和家庭折上重新拟合原交互参考、仅钠密度、原饮食加钠主效应，以及同时保留原交互并加入钠 × 肠道 PC5。最后一个增量比较固定同一原饮食交互，用训练折正交化后的钠交互估计额外预测修正。

沿用已部署的 `Full_pheno_v6` 和 `Full_pheno_v6_exposure` 以及 v5 环境。该分支沿用探索发现样本，区间用家庭同步重抽样并覆盖该分支所有比较。
