# Full_pheno · Diet × microbiome effect modification

这个目录收纳全表型实验。每个版本单独上传、运行和存结果，新增实验放在新的子目录。

查看 [v1–v5 实验总览](SUMMARY.md)，包括各版主要结果、18 组逐项对照和两种交互占比。

| 版本 | 研究问题 |
|---|---|
| [v1](v1/README.md) | 同访视血糖先对齐，再检查固定三菌＋肠道 Shannon 交互能否扩展到九个表型；另可单跑 UPF |
| [Full_pheno_v2](Full_pheno_v2/README.md) | 复核 v1 结果，在两种饮食×九个表型上比较模型的覆盖面 |
| [Full_pheno_v3](Full_pheno_v3/README.md) | 固定纤维→血糖分支，比较其余 17 组的逐组选模、加权融合及同领域共享 |
| [Full_pheno_v4](Full_pheno_v4/README.md) | 试验保守收缩、稳健交互及同类表型借力，新增无饮食配对基线 |
| [Full_pheno_v5](Full_pheno_v5/README.md) | 以缩半 PC5 为对照，试验低维非线性交互和受限融合，比较增量与覆盖面 |
