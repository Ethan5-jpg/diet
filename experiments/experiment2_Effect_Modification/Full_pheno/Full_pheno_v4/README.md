# Full_pheno_v4 · 保守交互与三臂计分

本轮仍评估纤维、超加工食品（UPF）× 九个表型。v3 的固定 PC5 流程在其余 17 组有 8 组为正，带门槛融合有 0 组为正。口腔 Shannon 曲线设置曾在 UPF→肝脏黏度达到 +0.2155 个 R² 百分点，18.11% 的占比点估计未通过分母检查。v4 把这两个旧设置保留为对照，检验保守拟合能否扩大正向组合、减少明显下降，同时报告饮食总预测贡献。

## 候选与流程

固定候选库共 **314** 个设置。保留 v3 的 202 个设置，再加 64 个分块岭回归和 48 个稳健权重岭回归设置。新增候选只使用现有主效应所包含的菌群方向。线性与曲线的饮食列在训练折中标准化，在拟合交互前将乘积列对共同主效应残差化。

- 分块岭回归用 8 种菌群表示和 4 种线性惩罚，曲线惩罚为线性的 4 倍或 16 倍。
- 稳健权重用 8 种菌群表示、线性或曲线两种形状和 3 种岭惩罚。依训练主效应残差的中位数和稳健尺度给大残差较小权重。留出者评分继续用平方误差。 [Huber 权重的统计背景](https://doi.org/10.1214/aoms/1177703732)
- 所有适用的旧、新候选可在固定库中比较。各组事后最大值单列为探索结果。血糖的固定库中省略 v3 的 36 个同域共享设置。纤维→血糖保留旧分支，只在两个统一设置对照中改用对应设置。

| 流程 | 其余 17 组的交互模型 |
|---|---|
| `v3_fixed_pc5`、`v3_guarded` | 逐项回放 v3 固定 PC5 和带门槛融合 |
| `uniform_pc5`、`uniform_oral` | 18 组都用同一固定设置，分别用肠道 PC5 或口腔 Shannon 曲线 |
| `pc5_half`、`pc5_quarter` | 固定 PC5 修正幅度缩到 50% 或 25% |
| `fixed_two_site` | PC5 修正权重 0.50，口腔 Shannon 曲线权重 0.15 |
| `core_calibrated` | 只在预先列出的 10 个旧核心设置里选方向并缩权 |
| `new_block_guarded`、`new_block_maximin` | 在新增设置里分别寻求整体增益或较好的最差内层折。后者要求内层四折均为正，并用各折自身的结局变异计算每折 ΔR² |
| `pc5_capped_mix` | 主流程。以缩权 PC5 为起点，辅助方向系数在混合前为 0.15 或 0.35，随后对混合整体缩权。最优混合需比缩权 PC5 多 +0.02 个内层 R² 百分点 |
| `peer_direction`、`peer_checked` | 同一饮食下，用其他同领域表型选择方向和最大权重。后者再用目标表型自己的内层评分检验并缩权。血糖的两个流程用核心候选缩权 |

主要内层门槛是至少 3/4 折为正、总体 ΔR² 至少 +0.03 个百分点。选模选权在外层训练家庭内部完成，每个外层留出家庭只用于所在折的评分。五折划分、样本准入、外层固定预处理及内层 CLR/PCA 重拟合沿用 v3。内层 UPF 使用外层训练家庭拟定的归档校准。预留家庭结局不参与。 [嵌套交叉验证的方法背景](https://doi.org/10.1186/1471-2105-7-91)

## 三臂及两种占比

每组使用同一批留出者及同一套结局变换。A 臂去掉目标饮食的线性、曲线及其与年龄、性别的乘积，保留饮食窗口的总能量调整、宿主协变量和菌群主效应。B 臂用原 v1 主效应模型。C 臂在 B 的预测上加该流程的饮食×菌群修正。

| 指标 | 公式与单位 |
|---|---|
| 交互 ΔR² | 100 × (R²_C − R²_B)，单位为 R² 百分点 |
| 饮食主效应块增量 | 100 × (R²_B − R²_A)，包含目标饮食及其与年龄、性别的乘积 |
| 饮食总预测贡献 | 100 × (R²_C − R²_A)，单位为 R² 百分点 |
| 占完整模型 R² | 100 × (R²_C − R²_B) / R²_C，沿用早先的占比定义 |
| 占饮食总贡献 | 100 × (R²_C − R²_B) / (R²_C − R²_A) |

两种占比都输出点估计及通过分母检查后的值。完整模型占比要求原结果和每次家庭重抽样的 B、C 两臂 R² 均大于 10⁻⁸。饮食占比要求所有饮食总贡献至少 +0.10 个 R² 百分点。检查未通过时保留绝对增量。饮食主效应块可为负，带符号的贡献占比可能超出 0–100%，应连同三个 R² 一起解释。这里评估预测贡献，原单位修饰差和因果解释需要各自的分析。

同步重抽样 9,999 次，给各流程的交互 ΔR²、饮食总贡献和相对 v3 固定 PC5 差值做同时区间。区间条件于已拟合预测，发现组结果用于后续验证前的比较。排名依次看其余 17 组达到 +0.10 个百分点的组数、正向组数、明显下降组数和中位增益。

终端另列适用于其余全部 17 组的固定设置的探索性覆盖排名，以及其余 17 组中、13 套流程里 ΔR² 至少 +0.10 且通过分母检查的两个最高占比。

## 运行与输出

将整个 `Full_pheno_v4` 上传到 `Full_pheno`，与 `v1`、`Full_pheno_v2` 和 `Full_pheno_v3` 同级。正式运行复用已完成的 `Full_pheno_v3/runs/TRE_ONLY/discovery-1` 与原发现组数据，先核对 v3 文件和登记指纹，再复现 v3 固定 PC5 与主融合的 18 组分数。

~~~bash
cd /home/ec2-user/studies/diet_gut_cgm_v2/multisystem_project_20261021/collaborator_handoff_20261102_v1/experiment2_Effect_Modification/Full_pheno/Full_pheno_v4 &&
bash server_run.sh --preflight &&
bash server_run.sh --threads 2
~~~

运行结束后用 `bash server_run.sh --report`。`workflow_scores.csv` 包含 13 套流程 × 18 组的三臂 R²、两种占比和区间，`workflow_comparisons.csv` 包含相对旧流程的配对差值，`library_screen.csv` 保存固定候选的探索点估计，`fold_choices.csv` 记录逐折的选模和权重。输出均为汇总。
