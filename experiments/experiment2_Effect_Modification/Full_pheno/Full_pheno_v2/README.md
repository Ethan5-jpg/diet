# Full_pheno_v2：比较跨表型的交互增益

目标：找一套固定的饮食×菌群预测方案，在原定的纤维、UPF × 九个表型中有广泛、可复核的绝对预测增益。所有方案保留同一个 v1 无交互模型，使用相同的发现家庭五折、合格样本和结局清洗规则。不对每个表型单独挑赢家，不读取预留组结局。

**实验顺序。** 先校验上传文件、v1 依赖和发现组输入。在同一轮拟合里重建 v1 三套预测，同时计算固定候选。18 组须逐项对上 v1 已保存的 R²、样本数、分折和数据登记，才汇总排名。新候选的交互列与已有主效应在训练折中作残差化；留出结局不参与拟合。

**候选。** 列表由 design.py 固定：三菌评分、肠道 Shannon、两者组合、双部位生态指标、口腔 PC5、肠道 PC5、双部位 PC5、三菌及 Shannon 加双部位 PC5。每种分别试线性剂量、线性＋曲线剂量和三种固定岭惩罚。另有四条共享路线：同一饮食下，用九个结局的标准化训练残差学习共同的交互系数方向，再允许各结局向自己的系数调整。不会把某个结局的留出家庭数据借给别的结局，也不使用验证者的其他表型做预测。

**怎么排名。** 18 组的 ΔR²（加交互减无交互）一律逐组计算。先按 ΔR² ≥ 0.10 个 R² 百分点的组数排序，同时报告 >0、≥0.25、≤−0.10 个百分点的组数、中位数、各饮食的组数及血糖/脂肪/肝脏各自的表现。0.10 是本轮的实用比较门槛，不是临床效应或显著性门槛。「多数」为至少 10/18；若只在单一饮食或领域有增益，不能称该模型跨饮食或跨领域均有效。每个方案使用同一套结构及超参数，允许用不同结局的训练数据估计不同系数。

同步按家庭重抽样，所有方案和结局共用一次抽样的家庭权重，保留结局之间的相关性。用标准化的最大偏差构造条件同时区间，覆盖全部候选×组合。报告有几个区间下限也达到门槛。区间以已拟合的发现组折外预测为条件，不能替代独立验证；对新模型不输出毫克/分升等原单位修饰差，v1 的修饰差仍留在 v1 结果中。交互占比只在两臂分母稳定时提供，不用于排名。联合重抽样处理相关比较的背景见 [Romano 和 Wolf](https://doi.org/10.1198/016214504000000539)；这里使用固定预测的单步最大偏差区间。

~~~bash
bash server_run.sh --preflight
bash server_run.sh --threads 2
bash server_run.sh --report
~~~

上传整个 `Full_pheno_v2`，与已运行的 `v1` 同级。正式运行要求 v1 的 18 个已完成结果仍在同级 `v1/runs/TRE_ONLY/discovery-1` 下。使用已固定的 V12 Python，可用 `HPP_FULL_PHENO_PYTHON` 指定同一解释器。结果写入 `Full_pheno_v2/runs/TRE_ONLY/discovery-1`（可用 `--run-id` 另存），含 18 组逐项结果和模型排名。预检仅用模拟数据。
