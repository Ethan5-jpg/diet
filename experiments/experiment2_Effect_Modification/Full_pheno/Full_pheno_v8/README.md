# Full Pheno v8 饮食主效应与交互稳定性

保留 v7 固定 1.37 倍的精度剂量交互参照和原半幅 PC5。比较把精度剂量加入关交互模型、将其与原主效应各取一半、按训练家庭分组平均岭回归系数、按表型域部分共享、以及在原肠道交互之外补充口腔 Shannon。嵌套流程只用内层留出家庭挑选是否替换四分之一或一半的参照预测。它要求完整模型的配对增益，且完整模型在内层优于无目标饮食。严格流程同时要求额外交互增益，保留流程容许至多 0.005 个百分点的内层交互损失。外折的纤维→平均血糖锚点继续使用固定的三菌＋Shannon。

在原分折和 v7 两套已核验的发现家庭分折上比较。优先选择达到联合门槛的分折更多、能跨分折保留同一达标组合的流程，再比较覆盖与退化指标。联合门槛保留原 9 个正向、2 个至少 +0.10、0 个低于或等于 −0.10 的标准，并要求达标组合的饮食总增量正向。选出的两套新流程和两套参照在两套新的家庭划分计分。重新分折复用发现组家庭，各自重拟合预处理及 UPF。预留家庭结局继续封存。

```bash
OPENBLAS_NUM_THREADS=2 "$HPP_FULL_PHENO_PYTHON" -B -m unittest test_rules test_reference
"$HPP_FULL_PHENO_PYTHON" -B -u run_stability.py --run-id stability-1 --commit "$CODE_COMMIT"
```

依赖已部署的 Full Pheno v1–v7，含 v7 的日记录精度和固定配方运行。按家庭同步重抽样 9,999 次，在各划分的比较集合内校正。每套分折保存一个可续跑的汇总检查点。模型结果保存在本目录的 TRE 运行路径。
