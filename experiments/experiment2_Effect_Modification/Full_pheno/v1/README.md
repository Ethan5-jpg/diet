# Full_pheno v1 · 纤维与菌群修饰的九表型实验

先用同访视人均血糖核对样本、分折和计分，再按同一固定模型评估九个表型。九项为平均 CGM 血糖、总脂肪、内脏脂肪、肝脏弹性、剪切波速度、黏度、衰减、频散、超声声速。默认只做纤维血糖对照。`fiber` 跑九项；UPF 是单列的扩展，`upf` 跑九项、`all` 跑全部 18 个组合。

## 比较的三套模型

三套共用相同人群、家庭划分、结局和主效应：年龄、性别、吸烟、暴露窗口能量、饮食曲线、饮食×年龄/性别、口腔和肠道生态指标及每部位前五个 PC，以及三菌评分和肠道 Shannon 主效应。主效应基线用最小二乘。A、B、C 在每一折只用训练家庭拟合，留出家庭仅用于评分。

| 模型 | 变化 |
|---|---|
| A `off` | 不含目标饮食×菌群项 |
| B `three_species` | A 加三菌交互。交互项为饮食曲线两列×三菌评分两列 |
| C `three_species_plus_shannon` | B 再加饮食曲线两列×线性 Shannon 交互 |

三菌评分是 `log1p((R. bromii + B. adolescentis + E. rectale)/0.0001)`，各项为原始相对丰度比例。由已登记的丰度列字典做物种末端精确匹配；允许 E. rectale 的 Agathobacter rectalis 别名，缺失或多重匹配即停止。Shannon 按整张肠道物种表重闭合后计算。固定纤维折点 12.5 g/1,000 kcal，剂量基函数继承线性加折线形式，训练内把曲线项对线性项残差化。三菌标准化与中位数折点也由训练样本估计。交互修正分别扣除 A 的共享主效应、A 加三菌乘积的空间，再用固定岭惩罚 `[.01, .01, .03, .03]` 和 `[.18, .54]` 拟合；评分定义和惩罚不按表型重新筛选。

这是对 11 月 18 日「三菌＋Shannon」结构的**同访视适配**。原结果的前后段血糖窗口、反向拟合混入的 25% 权重以及原日级营养背景属于那个实验；这里使用九表型共用的交接协变量和同访视口径。不能把原 14.69% 当本次预期值。这一版只在发现组运行。

**血糖参照。** 复用 W20 已登记的五折家庭划分，也就是 v10 的 r0 划分（纤维血糖留出人数应为 661/677/668/665/672，总 3,343 人、3,059 家庭）。若实验父目录中的旧 `v10` 完成档存在，直接核对模型设计、V10 源输入及各折文件哈希，检查每折参与者、家庭键和实际折外血糖完全一致，才重算 `total_plus_omit_bromii@0.01` 的自己 off/on 分数。V10 是另一套模型，各自与自己的无交互臂比。旧档缺失或有差异会报告原因，仍可完成 A/B/C 的配对。旧的日期拆分 14.69% 单独保留。

## 评分、修饰差和数据口径

- **预测**：每个结局用自己的合格参与者。按原 W20 训练折重算 Y：最短 95% 区间估计中心和标准差，超过 8 SD 排除，其余截尾至 5 SD。人数对照归档的每折准入表；训练和留出家庭不能重叠。口腔/肠道 PC 只使用同一折已登记缓存，不能用 `full` 的 PC 做折外预测。
- **ΔR²**：合并五个留出折，用同一批留出结局的均值定义 SST。报告 B−A、C−B 及 C−A。交互总占比 = `100 × (R²_C − R²_A)/R²_C`；额外 Shannon 行的占比用 `100 × (R²_C − R²_B)/R²_C`。符号保留。若该对照中的任一臂在观测样本或任一家庭重抽样中的 R² 不大于 1e−8，比例显示 NA，仍报告 ΔR²。家庭配对重抽样 9,999 次，固定已拟合的预测。B−A 给描述性的逐项区间；C−A、C−B 各给逐项区间和两个对照×九结局 Bonferroni 区间，纤维、UPF 分开。区间不包含开发历史、重新拟合或独立队列的不确定性。
- **原单位修饰差**：另做同一批折外评分者的联合关联回归。用原单位未截尾的 Y、全发现预处理的 PC，两种菌群交互同时入模。控制其余变量及另一菌群标记，分别比较高（Q75）与低（Q25）时纤维从 10 到 15 g/1,000 kcal 对应的预测变化差。高低两端都检查暴露范围和剂量附近的人数。覆盖不足、交互不可估计或背景特征欠缺时，修饰差显示 NA，保留可用的配对预测结果。用家庭聚类 CR1 标准误，另外报告两标记×九结局的 Bonferroni 区间。它是描述性条件关联，和上面的折外预测增益是不同的量。
- **UPF 扩展**：以已登记折缓存里的概率校准 `UPF_u/UPF_h` 表示 UPF（`UPF_h` 保留原基函数的概率积分）。原单位修饰差用单独的线性交互，比较校准比例 20%→30%，同时保留非线性 UPF 主效应。

## 上传与运行

把整个 `Full_pheno` 上传到服务器已有的 `experiment2_Effect_Modification/` 下。`server_run.sh` 默认调用旧 V12 `.python_path` 里已固定版本的 Python；也可通过 `HPP_FULL_PHENO_PYTHON` 指定同一解释器。代码使用原交接包 `manifests/payload_sha256_final.json` 登记的发现组输入，先核对 schema/行数，实际用到的字节按登记核验。`--preflight` 只用生成数据（包括 18 个组合的端到端验收）。

先做血糖核对，在服务器终端执行：

~~~bash
cd /home/ec2-user/studies/diet_gut_cgm_v2/multisystem_project_20261021/collaborator_handoff_20261102_v1/experiment2_Effect_Modification/Full_pheno/v1 &&
bash server_run.sh --preflight &&
bash server_run.sh --inventory --scope fiber &&
bash server_run.sh --scope bridge --threads 2
~~~

看到 `FULL_PHENO_V1_COMPLETE`、血糖分折人数对齐就可以跑全量。正负增益不作停跑条件。用相同参数重跑会校验并复用已完成组合。

~~~bash
bash server_run.sh --scope fiber --threads 2
bash server_run.sh --report --scope fiber
~~~

若要补齐 UPF，在纤维完成后运行：

~~~bash
bash server_run.sh --scope all --threads 2
bash server_run.sh --report --scope all
~~~

结果位于 `runs/TRE_ONLY/discovery-1/`。`fiber_summary.md` 和 `fiber_summary.csv` 是九项汇总，`all_summary.*` 是 18 项。每个组合的 JSON 记录各折人数、两类区间、剂量覆盖和校验信息。输出均为汇总；模型和逐人数据不写入结果目录。现有运行与上传包、源清单、运行设置不一致会停止，另起实验时使用新版本子目录或新的 `--run-id`。
