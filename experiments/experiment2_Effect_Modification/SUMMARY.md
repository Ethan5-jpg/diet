# Experiment 2 · HPP 饮食、菌群与血糖修饰效应总报告

截至 2026-11-14。覆盖本目录 v1–v5，以及直接相关的 V11、V12 和口腔功能先导结果。结果依据实验记录和服务器汇总。

## 主要发现

v5 在 **1,447 人、1,342 个 HPP 预留家庭**中，固定三菌交互使人均血糖预测 R² 从 **10.128% 降到 10.011%**，配对 **ΔR² = −0.117 个百分点**，家庭重抽样 95% 区间 **[−0.475, +0.238] 个百分点**。同一批人的联合线性模型给出肠道 Shannon **+0.403 mg/dL**、三菌评分 **−0.430 mg/dL** 的条件修饰差，方向与发现组一致，两项校正区间均跨零。 [v5 正式评分与联合分析](v5/PLAN.md#2026-11-14-预留组正式结果)

## 研究问题与指标

- **修饰差（mg/dL）**。在人均纤维分析中，比较纤维密度 10→15 g/1,000 kcal 对应的血糖关联，在菌群指标 Q75 与 Q25 时相差多少。正值表示高菌群指标下的纤维–血糖关联更偏正向。v5 联合模型固定发现组的分位值，并在改变一个菌群指标时保持另一个相同。
- **配对 ΔR²**。在同一批评价对象上，用加交互模型的 R² 减去匹配基线 R²。基线已含相应主效应。原始 ΔR² 为 0.001 时，等于 0.1 个 R² 百分点。下文预测表使用 R² 小数，标为“百分点”的结果除外。
- **历史总预测**。V11 融合模型两轮总 R² 为 0.130555、0.139855。各修饰实验用各自的配对基线计算增量。两轮发现组家庭分折复用同一批人，用于检验换折敏感性。 [V11 总预测](../diet_model_distribution_20261109_v11/RESULTS_SUMMARY.md) · [v5 固定比较](v5/PLAN.md#固定主比较)

## 二、日级数据核对与补充结果

- **日级数据可用性。** 发现样本有 21,705 个饮食与 CGM 同日配对，覆盖 3,284 人。其中 3,025 人至少有 3 个共同有效日。距最近共同日的样本登记日期间隔中位数，肠道为 11 天、口腔为 69 天。肠道登记字段可指交样日期，精确采集时间与先后关系仍有限制。 [配对与日期核对](v1/research_records/2026-11-11_followup_data_check/2026-11-11_174005_daily_link_verified/record.md)
- **较早的 W20 日级补充。** 3,028 人、21,279 人日。学习型口腔与肠道评分的交互区间均跨零，联合探索性 P≈0.0935。加交互后的同批拟合 R² 增量约 +0.000392。 [W20 日级分析](../../HPP_Full_Code_With_Models_20261102_v2/04_DOCUMENTATION/reports/HPP_W20_Targeted_V3_Daily_CGM_2026-11-01.md)
