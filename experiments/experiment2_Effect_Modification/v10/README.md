# v10　纤维与肠道菌群交互的配对预测实验

V9 发现组中，固定三菌评分曲线模型 `standalone_score_surface_fermentation@0.01` 在两次按家庭划分的交叉验证中得到 **9.270% 和 9.863%**，对应的绝对 ΔR² 为 **0.803 和 0.861 个 R² 百分点**。本轮的判定标准是同一固定模型、同一固定参数，在两套划分中都严格超过 **10.00%**。使用相同的 3,343 人、3,059 个家庭、纤维密度和人均血糖结局 `D_Glu`。研究量是交互对该模型样本外预测的贡献。生物机制和因果效应属于进一步验证的问题。

## 比较的内容

| 实验 | 具体比较 |
|---|---|
| 三个 V9 对照 | 肠道三菌评分、Shannon、两者联合的曲面。每个对照复算 V9 的八个惩罚值。三菌评分使用三种肠道菌相对丰度之和，再取 `log1p(总丰度 / 0.0001)`。 |
| 评分形状 | 比较训练折不同分位数处的折线、双折点和三折点、不同平滑宽度、秩变换、限幅、饱和、自然三次样条和径向基。 |
| 纤维曲线 | 比较线性、历史纤维曲线、单折点和双折点、尾部、自然样条、平滑折线和局部径向基，并交叉搭配三种评分表示。 |
| 差异化正则化 | 分别调整线性纤维、弯曲纤维、评分折点以及两者同时弯曲的交互系数惩罚。岭惩罚细化到 0.001，覆盖 V9 最优设置 0.01 的两侧。 |
| 三菌组成 | 分别去掉 *R. bromii*、*B. adolescentis*、*E. rectale*，或者用各单菌评分、菌间对数丰度差、检出状态、面板内优势度和均匀度。另外将六种替代评分分别叠加到原三菌模型。 |
| 与其他菌群特征叠加 | 在原三菌曲面上叠加肠道 Shannon、Shannon 与三菌的乘积、前四个肠道 PC、或三菌评分与前两个 PC 的乘积。各乘积对应的低阶菌群或剂量主效应在两臂共享。 |
| 本次新增的两个四格对照 | 以历史三菌曲面为起点，检验两个额外交互块能否互补。第一个块是纤维在训练组第 35 百分位处的折点 × 三菌评分及其折点；第二个块在第一组使用三菌内部的两个对数丰度对比，在第二组使用 Shannon 及其中位数折点，均与原纤维基底相乘。每组四格：原交互、只加剂量块、只加菌群块、两者都加。四格关闭预测逐人相同，所有新增变量的主效应始终保留。 |
| 其他估计和组合 | 在六种结构上另用弹性网或主成分回归估计交互系数。另设固定比例的交互预测收缩及九组配对预测平均。 |
| 区分主效应与交互结构 | 五个模型共享较丰富的加性主效应，只替换交互形状。在相同关闭预测上直接计算相对该组对照的差和配对区间，写入 `summary.json` 的 `common_background`。另用八种组合拆解历史三菌模型，固定惩罚 0.01，在纤维线性项 × 三菌线性项基础上逐项加入其余三个乘积，报告各项平均新增的 R² 及家庭重抽样区间。 |

共 **143 种岭回归结构、12 种其他估计方案、6 种交互幅度收缩、9 种固定组合**，合计 **170 个模型族、1,798 个固定设置**。新增的是 8 个结构 × 11 个惩罚，共 88 个固定设置。另有三个自适应规则，只在外层训练家庭的两套内层三折划分中选参。正式运行会保存所有结果。分组、精确特征、参数、权重和顺序见 `design.json`。

预先指定的主要新方案是 `ensemble_knot_neighborhood@0.01`。它在开启和关闭交互的预测中，都给训练折中位数折点的模型 50% 权重，给第 40 和第 60 百分位折点各 25%。这样可以检验在相邻折点上平均预测能否改善较弱的那次划分。其余固定方案也分别参加同一阈值比较。

## 如何计算及读结果

1. 每个模型用自己的主效应模型作对照。人群、家庭划分、宿主与饮食项、菌群主效应、预处理和主效应惩罚逐项配对。两臂分别拟合系数，开启时增加指定的纤维与菌群乘积。固定组合对两臂用相同的父模型和权重。样条折点、尺度和微生物主成分只从相应训练角色估计。
2. 每次划分合并五个外层测试折，逐人计算 `R² = 1 − SSE/SST`。在该划分相同结局和行上算 `ΔR² = R²_on − R²_off`，再算 `占比 = 100 × ΔR² / R²_on`。每个外层折另用纯主效应求解器复核全部 170 个族的关闭预测（容差 2×10⁻⁸ mg/dL）；报告按模型名取对照，用逐人误差平方和独立复核每个设置的两臂 R²。正分母下，判断 `100 × (SSE_off − SSE_on) − 10 × (SST − SSE_on) > 0`，不依赖显示的小数位；只在浮点求和误差范围内按相等处理。R² 从 0.081 升到 0.090，绝对增量是 0.9 个 R² 百分点，占比恰好 10%，不算过线。若同一族 r0 的 0.01 过线、r1 的 0.03 过线，但都只过一次，也不算。
3. 固定方案在十个外层折使用同一设置，各折系数由各自训练家庭估计。按两次占比中较小的值排序。稳定性沿用 V8 定义：两臂 R² 的家庭区间下端均高于 10⁻⁸，每个有效重抽样的完整模型 R² 也高于该值。分母不稳单列。自适应规则的两套内层划分只在双方都可评分的训练组人员上评估，各内层折仍使用其训练角色确定的结局预处理，实际共同人数保存在 `inner_population`。选择按两次中较小的占比，另有基线保护和跨类组合。基线保护要求两套内层主效应 R² 均至少达到历史三菌对照的 R² 减 0.002。无正增益时回到该对照的关闭预测。自适应策略可以逐折换参数，单独报告，不计入固定设置过线数。
4. 对 1,999 组家庭重抽样，所有模型、两套划分共用抽到的家庭。单模型的区间以已拟合的外层预测为条件。搜索校正针对本轮全部 1,798 个固定设置和三个自适应规则，使用 `100 × ΔR² − 10 × R²_on` 的同步单侧下界。两次下界均为正且分母稳定才计入 `adjusted`。同一批家庭被重新划分，往轮搜索和模型重新训练的不确定性均未计入该区间。数据范围限于发现组。

| 输出 | 读法 |

| `EXP2_V10_BOTH` | `point` 表示同一固定设置两次点估计都过 10%。`stable_point` 同时要求分母稳定，`adjusted` 还要求本轮搜索校正后过线。另列其中两次绝对 ΔR² 均至少达到 V9 对照的设置数。 |
| `EXP2_V10_GAIN_CHECK` | 在占比过线且分母稳定的设置里，进一步数出两次划分的绝对 ΔR² 和完整模型 R² 都至少达到历史三菌对照的设置。 |
