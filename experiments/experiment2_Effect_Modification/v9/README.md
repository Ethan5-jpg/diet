# V9　纤维与菌群交互的配对批量实验

实验在同一发现组的 3,343 人、3,059 个家庭中比较膳食纤维密度与人均血糖结局 `D_Glu`（mg/dL）的预测。V8 的 `pc4_marker_gate_both` 在两次家庭划分得到 7.622% 和 5.270%，较低一次距离 6.46% 还有 1.190 个百分点。V9 预先固定候选，按**同一方案两次结果中的较低值**排序。真实 HPP 结果由服务器运行产生。

cd /home/ec2-user/studies/diet_gut_cgm_v2/multisystem_project_20261021/collaborator_handoff_20261102_v1/experiment2_Effect_Modification/v9 &&

中断后用原命令、原线程数重跑即可复用已完成的外层折。默认两个线程。每个外层折训练前打印 `EXP2_V9_START`，写完后打印 `EXP2_V9_OUTER_COMPLETE`。若前一次进程被强行终止并留下运行锁，先按报出的主机和进程号核实其状态。已完成的 V8 对照结果会在所有 V9 外层预测生成后读取。找到归档时，程序检查旧结果完整性、两套划分的十个外层折、33 个 V8 模型族的人员、结局、选参、交互开关和逐人预测。预测容差为 2×10⁻⁸ mg/dL。归档缺失时，输出明确标记对照为本次重算。

### 本次补充的两个对照

**共用一个关闭模型。** 八个组合都保留 PC4 方案全部主效应，关闭交互时要求它们对每个人的预测完全一致。八个开启模型都包含纤维与肠道 PC10、Shannon、三菌评分的基本交互。三组可开关的额外项分别是Shannon 与前四个 PC 共同修饰纤维斜率、三菌评分与前四个 PC 共同修饰纤维斜率、三菌评分与纤维非线性剂量曲线的交互。八种组合中有两个已有模型，补齐其余六个。所有组合都走完整参数网格。为解释叠加增益，额外固定岭惩罚为 0.1，按三组项的六种加入顺序平均各自贡献，单位为 R² 百分点。三个贡献之和等于完整模型相对基本交互模型的 R² 改善。输出还列出从完整模型单独去掉每一组的变化。它们刻画这三个模块在本次预测模型中的增益。

**只缩小新增交互预测。** 对历史固定 PC10 所在模型族、PC10 加两种评分、PC4 门控、生态评分轻惩罚、三菌剂量曲线和三种历史办法的完整组合，各设 25%、50%、75% 三档。新预测等于 `关闭预测 + 保留比例 × (原开启预测 − 关闭预测)`，每次比较都复用该父模型逐人相同的关闭预测。这个检查针对交互方向有信息、拟合幅度偏大的情形。六种父模型仍同时报告原始幅度。

## 配对计算和选择

对每个方案，同一批外层测试家庭得到一对预测。关闭交互的模型保留该方案的宿主、饮食和菌群主效应，开启模型加入纤维与菌群的乘积项。两边用同一批训练行、预处理、主效应惩罚及设置。拟合时允许两边各自重新估计主效应系数。树的叶组等数据驱动坐标只由当前训练折学习，再在配对两臂共享。

每次家庭划分分别合并五个外层测试折，使用该次相同的人和结局总离差平方和计算两个 R²。

```text
ΔR² = R²_on − R²_off
交互预测增益占比（%）= 100 × ΔR² / R²_on
排序分数 = min(r0 占比, r1 占比)
```

输出的 `delta_r2_pp` 已乘 100，单位是 R² 百分点。占比描述在该模型解释的预测变异中，开启交互带来的相对增益。两次重新划分使用同一发现人群。V9 根据此前发现组结果设计，这批结果适合筛选候选。

模型族表使用两套按家庭分组的三折内层预测。对每一参数设置，先取两个内层占比的较低值，再按这个值选参。计算只纳入两个内层预测都覆盖的训练人员。内层关闭和开启模型的 R² 均须为正。所有设置在内层均未见正增益时，该族在当前外层折使用相同的关闭预测作为两臂。已选设置在外层表现为负时如实保留。同一模型族可在不同训练折选到不同惩罚。

固定参数表直接评估每个“模型名@参数”。同一个设置在两次划分的十个外层折均按预定参数拟合并开启交互，永远与自己的关闭预测比较。固定等权组合的权重也完全相同。以这张表判断某个具体设置能否在两次划分中都超过 6.46%。

树使用纤维坐标与训练集加性背景残差的乘积作为分组目标，背景为宿主、剂量、两部位前五个 PC 及两种肠道评分。肠道浅树有两种深度，另有加入口腔坐标的浅树。每种取五棵树，最小叶组至少 6 人且至少占当前训练人数的 4%。聚类使用菌群坐标。叶组和聚类均在两臂加入相同组别主效应。相同训练折内，弹性网、主成分回归及有限步共轭梯度均处理相同的标准化、带惩罚权重的交互块，使用 0.15 的共同二次收缩。组成表示、降维、分组和曲线参数均在各自训练折生成。

主要组合规则 `stack_from_pc4` 保留 V8 起点的权重。每一步在各模型类别内先提名最多三个内层表现好的单模型，然后尝试给候选分配 25%、50% 或 75%。最多四个组成模型。每次同时混合各模型的关闭预测和开启预测并重新计算占比。另报告不限起点的组合、最大化两次较低占比的选模、要求基线表现稳定的选模、以及跨类别前三名等权平均。
