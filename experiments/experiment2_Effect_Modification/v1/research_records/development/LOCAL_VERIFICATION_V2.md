# Experiment2 v2 本地验证

运行名为 experiment2_20261110_v2。发现样本、结局、家庭外折及评估人群沿用既定口径。20 条新增路线和 26 条原路线共用新版基线。原候选池选择器与扩展候选池选择器在同一基线上比较。

| 检查 | 本地观察 |
| --- | --- |
| 上传和环境 | 13 个运行与测试文件的 SHA256 校验通过。沿用现有 Python 3.11 和已锁定的包 |
| 内外折隔离 | 跑完两个重复的十个外折。扰动一个外折的全部留出结局后，该折选择、融合权重、预测和纤维对比逐值一致 |
| 近共线回放 | 同一合成剂量场景，稳定化前样条最大修正为 205.685 mg/dL，最终版降至 19.560 mg/dL。最终版保留投影方向的条件数低于 200 |

| 服务器目录布局模拟 | 原命令入口使用 4,427 个生成样本，锁定 3,343 人和 3,059 个家庭。一折暂停，续跑其余九折并生成四屏报告。两个重复均恢复植入的岭交互 |
