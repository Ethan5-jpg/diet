# Experiment2 v2 本地验证

运行名为 experiment2_20261110_v2。v1 发布包的 13 项运行文件通过原 SHA256 校验。v2 另存，包含 56 条原路线和 9 条新增路线。

| 检查 | 本地观察 |
| --- | --- |
| 定向信号 | 训练筛查定位了植入的第 48 个菌种信号并恢复了留出剂量交互。分组惩罚选中植入的 PC 组。双成分提升树恢复了随菌群分组改变的剂量曲率 |
| v1 匹配外折 | 用相同的生成数据分别运行 v1 与 v2。共同基线、56 条原路线、岭选择器、v1 候选池选择器的预测和纤维对比一致，绝对容差为 1e-9。留出行、结局和局部剂量支持逐值一致 |
| 完整模拟 | 65 条路线在 960 个生成样本上跑完十折。通过留出结局扰动、近共线回放、错误折与损坏检查点拒绝。纯可加外折中 65 条路线均选回零修正 |
| 服务器目录布局 | 使用 4,427 个生成样本，锁定 3,343 人及 3,059 个家庭。从 experiments/experiment2/v2 启动，一折暂停后续跑其余九折，完整生成六屏报告。56 条原路线的两轮 ΔR²、实际施加修正次数和对比标准差与 v1 的同一模拟一致 |
| 完成状态 | 模拟最终报告损坏后，入口拒绝校验且不输出 EXP2_COMPLETE |

所有分数验证均使用生成数据。真实 HPP 输入与预测表现由服务器运行核验。
