# Experiment2 Implementation Plan

**目标：** 在同一发现样本和家庭外折中，公平检验非岭方法能否提高纤维密度×菌群交互的折外增量，并以 +0.01、+0.04、+0.05 为描述性参照。

**结构：** 复用冻结 V12 数据与主效应构造，补充固定的无饮食菌群主效应基底。交互学习器从同一主效应参照出发，在训练角色把交互候选的可加部分投影掉。只在内折选择惩罚、结构和融合；外折同人配对评价。全部候选以及负值保留。

**环境：** 现有 pheno / V8 Python 3.11，NumPy、SciPy、scikit-learn、pandas、PyArrow、threadpoolctl；不安装包。

1. 在 experiment2/exp2_design.py 构造训练内基底、可加参照、秩保护投影及固定纤维对比。旧 V12 主效应成绩仅作历史背景，不参与新交互的差值计算。
2. 在 exp2_models.py 实现固定岭对照、稀疏混合字典、CLR 随机傅里叶基底、Hellinger Nyström、斜率森林、斜率提升树、有限宽度神经斜率。提供各路线精确零修正。
3. 在 exp2_engine.py 完成家庭嵌套、同参照损失选择、岭/非岭/全族选择器和约束融合，逐折保存选项与全部评价结果。计算折外配对区间、原始结局评分和固定纤维对比诊断。
4. 在 exp2_run.py、exp2_store.py、server_run.sh 连接发现集并检查旧源码、分折和结局一致性。输出只进新运行目录；使用内存压缩/顺序写入、校验和、锁与可恢复外折。先做不读取原生数据的预检。
5. 本地执行生成数据检查：精确零修正选择、已知非线性交互、原生布局模拟、隔离和验证结局扰动、投影对比回放、投影目标的神经梯度、完整候选网格/十折、顺序写入和篡改拒绝。在 research_records 保存检查结果，附终端指令和运行方法。

**证据标准：** 主要展示预定的非岭选择器与同一基准；单模型榜单为发现期诊断，不能把最好的外折结果当独立验证。阈值只在同一路线两轮均超过时计为达到。报告是否超过同样本岭交互而非借改变背景抬分。没有学长原始的配对分数及评估口径，不声称已经复现其一个点。
