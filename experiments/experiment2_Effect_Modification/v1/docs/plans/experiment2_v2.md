# Experiment2 v2 扩展计划

目标是让增加的候选检验不同的纤维 × 菌群关系，并在同一套外折上比较扩展候选池、旧候选池和强化后的岭回归对照。

1. 核对角色隔离、数据入口、零选项、融合、外折收据和报告。修复单个求解器失败导致整批停止的情况，记录内折失效和外折退回零修正。
2. 在相同角色上构造原菌种、剂量折线及口腔 × 肠道 PC 张量，同时将这些字典的单独主效应加入共同基线。实现稀疏菌种、PLS、非线性核 × 样条、剂量折线、近邻斜率、跨部位协同及扩充岭对照。
3. 加入旧扩展候选池选择器。外折另报扩大池相对旧池的配对差。保存全部路线和两个分折结果。
4. 对压力测试发现的近共线回放放大，改用有条件数上限的截断奇异值分解，增加近共线和异常修正的回归检查。
5. 增加独立 v2 运行名，验证 v1 报告兼容性。跑真实入口布局的十折生成数据，验证暂停、续跑和报告。运行有已知交互的正对照、精确可加对照和单设置失效的针对性回归检查。
