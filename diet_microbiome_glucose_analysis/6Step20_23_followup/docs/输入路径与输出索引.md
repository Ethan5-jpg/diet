# 输入路径与输出索引

以下路径均相对HPP的`Data`目录。运行时默认根据新包的位置定位；支持`--data-root`整体迁移。

| 输入 | 相对路径或定位依据 |
|---|---|
| Step19b清单 | diet_microbiome_glucose_analysis/5Step19b_core_taxa_direction/outputs/已确认运行/manifest.json |
| 1490候选、三模型和871方向 | 上述manifest中的原输入/selected_models及19b_path_direction_details.csv |
| 分析CGM表 | 三套模型reports/manifest.json中的final_cgm，要求当前文件内容一致 |
| 原IGLU导出 | Transfer/cgm/iglu.csv |
| 既有饮食 | diet_microbiome_glucose_analysis/outputs/data/00_current4_diet_cgm_cohort.csv |
| 新饮食及能量 | diet_microbiome_glucose_analysis/outputs/new_diet_extension/data/15d0_new_diet_cgm_cohort.csv |

| protocol抗生素/PPI | diet_microbiome_glucose_analysis/outputs/new_diet_extension/mediation/protocol_abxppi/15f2_protocol_abxppi_cohort.csv |
| 原18g冗余审计 | diet_microbiome_glucose_analysis/4New_cgm/outputs/paper20_mediation_phenotype_domains/reports/18g_mean_gmi_redundancy_audit.csv（存在时读取并比较） |

不执行旧脚本，不导入带服务器绝对路径及自动建目录副作用的旧模块。

每次新建的输出目录中：

- `SCREENSHOT_SUMMARY.txt`：总状态；`STEP20/21/22/23_SUMMARY.txt`：分段摘要。
- `tables/20_field_lineage_audit.csv`：逐字段raw来源匹配和clean→Z核查。
- `tables/20_*_spearman.csv`、`*_pearson.csv`、`*_pairwise_N.csv`：五个人群口径的25项矩阵，20项主图单独绘制；完整矩阵保留补充5项的独立标识。
- `tables/20_domain_denominators_and_retention.csv`：完整20、去GMI19、概念面板9三种描述；分母与比例列明确命名。
- `tables/20_outcome_denominators_and_retention.csv`及`20_diet_domain_*`：细化表，包括零候选结局。分母为零时比例留空，不能写成0%。
- `tables/20_taxon_domain_breadth_redundancy_checks.csv`：删去重复/简化面板后的领域覆盖，允许降为0，不改原核心标签。
- `tables/21_path_sample_reconstruction.csv`：逐路径N与样本哈希；`21_all1490_three_model_results.csv`：原模型补充结果。
- `tables/21_existing_global_FDR_sensitivity.csv`：原有全局FDR；`21_frozen_mediation_FDR_families.csv`：每个实际家族大小。
- `tables/21_mediated_proportion_interpretation_flags.csv`：近零总效应与不一致方向提醒，不是新排除名单。
- `tables/21_CGM_raw_clean_audit.csv`、`21_CGM_preprocessing_record_inventory.csv`、`21_SDw_source_code_candidates.csv`：清洗过程可追溯性线索。
- `tables/22_*`：全部菌路径背景、证据矩阵、有限文献起点、按名字连接外部证据的候选表及功能数据盘点。
- `tables/23_forest_selected_paths.csv`：森林图全部选中原始路径，避免只有图而无法追溯。
- `figures/`：5组PNG和矢量PDF（数据核查失败时依赖图可跳过）。
- `reports/结果与方法草稿.md`：本次结果段落、方法框架、解释边界。
- `manifest.json`：参数、实际文件SHA256、代码/配置版本、状态和软件版本。
- `aggregate_results.zip`：以上汇总材料。不包含参与者矩阵，仍应作为研究结果资料按项目权限管理。

相关性口径分别是全部冻结CGM人群、primary基础人群、strict基础人群、进入任一primary冻结候选路径的样本并集、相应strict样本并集。基础人群仍可能因某饮食的额外协变量、特定菌或结局缺失而无法进入某条路径；不能用基础人群N替代路径N。
