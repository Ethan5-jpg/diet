# Step20–23 实施计划

授权范围：用户要求准备后续分析，整理为上传服务器即可运行的文件夹。仅在新文件夹内开发；沿用已冻结的结果，不重新筛选、拟合、bootstrap或计算FDR。

1. 核对HPP官方字段字典及IGLU文档，分开记录公开定义、导出值匹配、清洗/Z检查及历史实现参数的可追溯程度。
2. 以已成功的Step19b运行清单和SHA256锁定1490候选及871保留路径。拒绝多版本猜选、损坏文件、重复路径或不一致标签。
3. Step20：重建primary/strict/protocol分析样本，按旧规则检查逐路径N和样本哈希；计算primary基础分析人群及strict对应人群的20/25项两两完整观测Pearson/Spearman相关和pairwise N。另报全部CGM人群，不能混称中介完整病例。
4. 汇总三个领域/各结局/各饮食的候选、primary稳健、strict/protocol保留及双重保留；同时报告候选分母和primary稳健分母。完整20、去GMI19、概念选取的9项简化面板并列，后两者为事后描述性检查。
5. Step21：保存原始三模型效果、CI、N、FDR、协变量、样本哈希；审查已有全局FDR、总效应接近零、间接与总效应方向不一致；不将单菌中介比例相加。
6. Step22：按完整taxonomy生成机制研究清单及证据矩阵，附已核实的定义来源和有限文献起点。功能/代谢组仅做文件存在性盘点，存在文件不等于可连接可分析。
7. Step23：生成矢量PDF及PNG相关图、保留率图、核心菌有序方向图和包括NOVA4/hPDI同结局的三模型森林图；输出来源清单、方法草稿及自动结果段落。
8. 验证：用明确标识的合成数据测试所有阶段、输入损坏、重复身份、缺失值、方向边界和样本不匹配；按Python3.8语法检查，并实际渲染检查图形。真实结果仅由用户在服务器运行产生。

数值定义修正不改变原871集合。SDw改为日内SD；COGI为较高分对应更佳控制的设计方向；GRADE eugly是GRADE贡献比例，不是TIR。相关路径数量不作为独立重复证据或富集检验。
