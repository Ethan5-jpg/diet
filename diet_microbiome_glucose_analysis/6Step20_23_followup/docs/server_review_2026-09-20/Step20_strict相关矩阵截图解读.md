## COGI及风险指标的解释

本图COGI与Mean为0.81，与LBGI为−0.89，与ADRR为−0.90，与CV为−0.52，与SDw为−0.03。这些是该strict样本中的秩相关结构，不等于各指标定义或因果效应。

[IGLU官方COGI文档](https://irinagain.github.io/iglu/reference/cogi.html)将其定义为结合目标范围时间、低于范围时间和波动分量的复合评分，当前默认权重为0.50、0.35、0.15，默认范围70–180 mg/dL。该构成提示应检查分量和样本分布，不能仅凭Mean–COGI正相关就推断“升高平均血糖会改善控制”，也不能据此判定字段方向错误。当前截图不能区分分量贡献、范围分布或历史参数的影响。

[IGLU官方GRADE eugly文档](https://irinagain.github.io/iglu/reference/grade_eugly.html)说明其为目标范围读数对总GRADE分值的贡献百分比，而非TIR。相关图不改变这一字段解释。[HPP官方CGM知识库](https://knowledgebase.pheno.ai/datasets/017-cgm.html)说明汇总特征使用IGLU，并将GMI列为Mean的线性变换；当前公开文档不证明HPP历史执行版本或参数。
