# HPP官方定义核查与解释修正

核查日期：2026-09-20。公开网页可以核实指标定义；服务器读取的raw列、连接身份和Z列必须另行核查。

| 分析字段 | 核实后的含义 | 本项目处理 |
|---|---|---|
| cgm_sdw | 每天葡萄糖标准差的平均值，即日内变异 | 新图改名SDw (within-day)，撤回旧Interday显示名；不改字段、数值或所属领域 |
| cgm_sdhhmm | 先对相同时刻跨天取平均，再对这些时刻均值取SD | 与SDw区别展示 |
| cgm_sdwsh | 对逐点起始的一小时窗口计算SD，再取平均 | 不是整天SD |
| cgm_sdb | 同一时刻跨天的SD，再跨时刻平均 | 补充指标，不用来替换SDw |
| cgm_sddm | 每日平均葡萄糖的跨天SD | 补充指标，不用来替换SDw |
| cgm_cogi | 综合TIR、低血糖和波动的控制评分；较高为设计上的较佳控制方向 | 正向间接效应不能自动解释为不利；也不能直接称为临床获益 |
| cgm_grade_eugly | 目标范围读数对GRADE总分的贡献百分比 | 不是正常范围时间比例，不能代替TIR；保留数值方向而不自动贴健康标签 |

HPP官方CGM知识库明确列出了这些字段，注明统计特征来自IGLU。网页的部分长描述有截断，因此计算细节以IGLU维护者文档补充。依据：[HPP官方CGM字典](https://knowledgebase.pheno.ai/datasets/017-cgm.html)、[IGLU SD子类型](https://irinagain.github.io/iglu/reference/sd_measures.html)。

IGLU当前公开的COGI默认权重是TIR 0.50、TBR 0.35、SD 0.15，TIR默认范围70–180 mg/dL。COGI原始研究给出0–100评分，较高值代表设计上的较佳葡萄糖控制。该研究主要在1型糖尿病干预数据中评估，不能把评分方向直接扩展成HPP中某菌的因果健康作用。依据：[IGLU COGI](https://irinagain.github.io/iglu/reference/cogi.html)、[COGI原始论文](https://pubmed.ncbi.nlm.nih.gov/30931606/)。

IGLU当前GRADE eugly默认目标范围为70–140 mg/dL。其分子是该范围内读数对应的GRADE贡献，分母是全部GRADE贡献。范围内时间增加与此比例不是同一量，单个方向不能替代总体控制评价。依据：[IGLU GRADE eugly](https://irinagain.github.io/iglu/reference/grade_eugly.html)。

**这些默认设置不证明HPP导出时实际使用了相同版本和参数。** 新包直接读取既有IGLU导出，不从CGM时间序列重新计算指标。

## 对已看到结果的解释修正

- T096和T107相关的COGI正向间接效应，应写成“与较高COGI评分相关”，不能统一并入“血糖恶化”。
- GRADE eugly正向只能写成“目标范围对GRADE的贡献比例较高”；不得写成TIR增加了相同数值。
- SDw对应路径讨论日内变异；不能继续作为日间变异证据。
- 同时出现Mean/GMI、LBGI、COGI不同正负方向并不自动构成矛盾；这些指标的含义和方向不同，且存在相关性。
- 所有效应仍是原分析Z单位；例如间接效应0.01并不等于COGI增加0.01原始分或TIR增加1%。

## 服务器自动检查

1. 用participant_id、cohort、research_stage、array_index、connection_id五个键对接分析CGM表和原IGLU导出。
2. 比较各字段raw值及缺失位置（允许上游合法性规则将负值或百分比越界值设缺失）。
3. 检查clean值在完整冻结CGM人群、按各指标非缺失值及样本SD（ddof=1）计算的Z是否等于已用Z列。
4. 记录raw→clean变化数量、清洗动作、原参数记录及SDw代码候选。缺少清洗动作记录不会被写成零次清洗。
5. 任一字段来源/Z失败时，相关性阶段不作为通过结果输出；其他独立汇总仍保留以便排错。

本地旧17项配置没有SDw。即便raw匹配且Z核查通过，SDw加入分析表的历史脚本及具体清洗参数仍应由服务器记录补全。新包会收集定位线索，不凭空补写处理历史。
