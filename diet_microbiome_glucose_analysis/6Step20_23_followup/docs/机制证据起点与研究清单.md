# 机制证据起点与研究清单

这是后续机制整理的起点，核查日期2026-09-20；目前核对的是原始论文摘要及可检索内容，没有冒充完成系统综述。结构化文献条目位于`config/literature_starting_evidence.csv`。

| 目标菌 | 可用原始证据 | 对HPP结论的限制 |
|---|---|---|
| Eubacterium rectale | 淀粉利用的分子机制及抗性淀粉补充的人群研究 | 支持研究底物利用/交叉喂养方向；不能直接把NOVA4或总碳水供能比等同抗性淀粉，更不能据此推断HPP内血糖改善 |
| Ruthenibacterium lactatiformans | 分离菌株发酵葡萄糖可产生D-乳酸、琥珀酸和乙酸 | 文献描述是产乳酸，不能由名称误写成乳酸利用菌或一概称为产丁酸菌；未验证HPP菌株和体内通量 |
| Clostridium phoceensis | 物种分离、表型和参考基因组描述 | 物种命名和基因组存在不等于已有饮食–血糖机制证据 |
| GGB6012_SGB8640 | 当前保留为未命名物种身份 | 未找到可确认的同一分类单元功能证据前，不根据近缘菌推断产酸能力 |

E. rectale的底物利用起点见[分子机制原始研究](https://pubmed.ncbi.nlm.nih.gov/25388295/)。20名健康青年抗性淀粉补充研究观察到个体丁酸反应差异，提示菌群背景可能影响发酵反应；它不能直接验证当前HPP的统计中介路径。见[人群补充研究](https://pubmed.ncbi.nlm.nih.gov/27357127/)。

R. lactatiformans的发酵产物来自原始分离株实验，尚未与本队列代谢物测量连接。见[物种与发酵研究](https://pubmed.ncbi.nlm.nih.gov/27154556/)。C. phoceensis先从参考株描述开展身份核查，尚不足以解释CGM方向。见[原始物种描述](https://pubmed.ncbi.nlm.nih.gov/27818774/)。

程序为全部109菌生成证据矩阵，按领域覆盖和原taxon_id整理。重点先审4个三领域菌，再审17个双领域菌；T019、T028、T107等应分别核对各饮食/结局的a、b及间接方向，不能只以路径总数排“好菌/坏菌”。同名物种可有不同株功能，按名字连接文献只是检索线索，完整taxonomy始终保留。

每条机制证据至少补齐：精确菌株/物种对应关系、饮食/底物、研究对象、观察或实验设计、功能/代谢物测量、方向、与HPP一致或相反的部分、反例及证据缺口。空白项表示未审，不表示不存在相关证据。

若服务器有HUMAnN/功能通路或代谢组文件，先审其参与者、访问时间、处理版本、缺失、批次和可连接关系，再单独制定分析。此次代码仅盘点候选文件，既不从菌名生成“预测功能数据”，也不自动开启新的关联检验。

Results可报告冻结的关联、领域覆盖及敏感性支持；Discussion将生物学线索写为待验证解释。现阶段不写“某菌通过某代谢物导致血糖改变”的确定链条。
