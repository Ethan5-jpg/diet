# HPP下一阶段实施建议

依据：截至2026-09-20已完成的Step19b及Step20–23截图核查。本文是建议与实施范围，不表示新增分析或机制综述已执行。假定下一阶段目标是形成可评审的观察性研究论文初稿。

## 建议顺序与交付物

| 顺序 | 工作 | 具体交付物 | 是否需要新增模型 |
|---|---|---|---|
| 1 | 方法与结果收尾 | 时间关系图、样本流程/基线表、冻结结果与敏感性汇总、待确认参数清单 | 主要复用既有结果 |
| 2 | E. rectale共同样本检查 | 六条重点路径的共同样本结果、三模型对照表与森林图 | 建议的有限事后敏感性分析 |
| 3 | 核心菌机制证据审查 | 首批7株的逐篇证据表、每株小结、相反证据与缺口 | 不需要 |
| 4 | 写Methods/Results并组织Discussion | 正文初稿、主图/补图目录、图注与配套表 | 不需要新增模型 |
| 条件扩展 | 功能/代谢组或纵向/外部验证 | 数据可用性与匹配人数报告，再单列分析方案 | 有合适数据时再开展 |

机制审查可以与前两项同步进行。把新增建模范围先限制在有明确问题的少数路径，不让写作等待无限扩展分析。

## 1. 必须明确的报告内容

1. 核实并画出饮食记录、粪便采集及CGM监测的时间关系与访视匹配规则。时间接近或同期测量不能自动提供“饮食先于菌、菌先于血糖”的时间顺序。
2. 复用既有人群流程和基线特征表，交代从CGM总人群到共同基础人群及逐路径完整病例样本的变化、缺失处理与变量版本。已有表先定位和引用，不重复生成相同内容。
3. 将原871条冻结路径列为既定主结果；832条三模型全局q共同通过路径、去GMI19指标及9指标面板分别列为敏感性结果。T046从三领域变两领域的具体条件必须保留。
4. 对历史IGLU版本、阈值、插值等执行参数设置有范围的追溯：优先查看既有manifest、环境锁定、日志与源脚本。找不到的内容明确标记未记录，不用当前公开默认值代替，也不让单个元数据缺口无限阻断其他整理。
5. 对COGI增加一个小型描述性核对：同一指定样本中查看其原始/清洗后分布及其与TIR、低于70比例、Mean和波动指标的相关关系，报告配对N。优先复用现有25指标相关表；若需要分位数才补只读汇总。这能帮助描述复合评分在本队列中的表现，不据相关性声称某个分量导致COGI变化，也不凭此倒推历史算法参数。

这些重点与[AGReMA中介分析报告指南](https://jamanetwork.com/journals/jama/fullarticle/2784353)对测量时序、模型假设、混杂与缺失处理、估计及不确定性的报告要求一致。具体实施优先级和下面的共同样本方案是结合本项目结果提出的建议，不是指南强制要求每个项目新增的分析。

## 2. 最值得考虑的新增分析：E. rectale共同样本敏感性

当前NOVA4六面板中的Primary N约3691–3693，hPDI约4136–4137；方向不同也伴随参与者构成不同。建议聚焦已展示的CV、MODD和SDw，不扩展到全部菌和全部结局。

范围与原则：

- 固定T068完整taxonomy、NOVA4/hPDI两项暴露及三个结局，共六条路径；若覆盖原三个模型，则报告18个估计，保持清晰的模型分组。
- 在每个模型、每个结局内，为两项饮食构建共同完整样本：两项饮食、该菌、该结局，以及两套原模型所需协变量的并集均完整，再分别使用各暴露原先规定的模型。按样本哈希确认同一对确实使用相同参与者。
- 沿用既有Z值和原协变量设定，先只改变样本选择，便于判断样本一致化后的变化。不同结局的共同样本N可以不同，不将它们写成统一固定N。
- 若之后需要统一协变量或将两项饮食同时放入模型，应先解释新的估计目标，再作为单独模型；不能把它与仅统一样本混在一起。
- 输出原样本与共同样本的N、a、b、间接效应及区间；对六条路径全部报告。此项回答“方向模式对样本构成是否敏感”，不自动完成两项饮食效应差异或交互作用检验。
- 这是查看原结果后提出的敏感性分析，不能包装成预注册验证。新的估计不直接继承原q值；如需作新增显著性判断，运行前写清相应检验集合和多重性处理。
- 原1490/871及现有FDR结果保留原样。新增结果单独保存，不能反向覆盖原冻结分析。

该检查可提高饮食情境解释的清晰度，但不消除横断面研究的时间顺序和未测量混杂限制。如果论文仅作描述性展示，当前结果也可先进入写作，并明确样本不同这一限制。

## 3. 机制审查首批聚焦7株

| 对象 | 本项目中优先审查的问题 |
|---|---|
| T068 Eubacterium rectale | 饮食底物证据能否与NOVA4/hPDI的定义对应；哪些研究测了功能，哪些只测丰度；相反结果是否与菌株、人群或测量方式有关 |
| T096 Ruthenibacterium lactatiformans | 核对真实物种/菌株的发酵证据，以及如何与本研究水平、LBGI和COGI方向比较 |
| T023 GGB6012_SGB8640 | 先核对同一SGB的身份、参考基因组及可追溯注释；没有对应证据时保留未知，不套用近缘菌功能 |
| T046 Clostridium phoceensis | 区分分类/基因组描述与饮食–血糖机制证据，同时报告其波动领域对全局FDR口径敏感 |
| T019 Alistipes ihumii | 审查已有较多水平/波动路径的外部证据及相反观察 |
| T028 Streptococcus salivarius | 检查不同饮食下方向模式的证据，并区分口腔来源、肠道检出与直接功能证明 |
| T107 Escherichia coli | 特别区分菌株差异、物种丰度和致病/代谢功能，不用物种名直接确定作用 |

每篇原始研究至少记录：精确物种/菌株、研究对象、设计、饮食/底物、是否直接测量代谢功能、结局与方向、与HPP的匹配程度、相反证据和限制。区分人群干预、观察性研究、动物、分离株/体外以及纯计算注释。每株输出一页证据小结和可用于Discussion的一段文字。

保留全部109株和17株双领域菌的已有完整结果；首批7株只是阅读与叙述优先级，不是重新筛选显著菌。未检索到或尚未审查不写成证据证明不存在。

## 4. 写作可立即同步开始

建议论文主线：不同饮食暴露涉及不同的菌—CGM统计路径；多个相关CGM结局提供覆盖信息，核心菌的领域覆盖需结合指标简化及统计口径解释。E. rectale的饮食情境差异作为重点实例，同时完整报告其他核心菌和敏感性例外。

先写Methods和Results，Discussion随证据表完善。正文结果至少覆盖人群、既有饮食–CGM总体关联、候选到冻结路径的流程、核心菌方向、敏感性结果。此前已完成的饮食–CGM总体结果应复用，不能让仅有中介示例代替总体暴露–结局结果。

主图可整合为研究/人群流程、饮食–CGM总体关联与指标相关结构、核心路径方向与敏感性、E. rectale重点森林图；完整路径、严格人群图和完整敏感性表进入补充材料。精确值以服务器结果表为准，通过短终端输出截图核对，无需下载。

## 5. 有数据时再扩展的层次

[HPP菌群官方页面](https://knowledgebase.pheno.ai/datasets/013-gut_microbiome.html)列出的标准结果包括测序/QC、URS相对丰度及MetaPhlAn分类丰度；该列表本身不确认当前已提供计算好的功能通路矩阵。

[HPP另有Nightingale血清代谢组数据集](https://knowledgebase.pheno.ai/datasets/029-nightingale_metabolomics.html)，公开页面列有代谢物结果和QC标签文件。但官方存在该数据集不意味着本项目已获得授权、已拿到文件或能与现有样本充分匹配。页面中2024年的覆盖人数也不能替代当前实际交集N。

若可用，先只做目录/字段与参与者–访视–时间匹配清点，再决定是否值得分析。血清代谢物并不自动等于肠道菌的特定产物；没有实测变量时不补出“某菌→某代谢物→血糖”的已验证链条。

若有真正独立的队列或恰当的纵向测量，可据此设计后续验证。已经查看全体结果后再随机拆分本队列，不能作为新的独立外部验证来叙述。
