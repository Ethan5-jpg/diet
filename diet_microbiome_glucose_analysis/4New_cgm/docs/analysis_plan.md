## 范围与设计

- 目录：`Data/diet_microbiome_glucose_analysis/4New_cgm`，可整体上传到服务器同一位置。
- 结局：MAGE、TAR180、TBR70、TIR70–180，读取已经 finalized 的扩展 CSV，使用现有 Z，不重算结局。
- 暴露：AHEI、AMED、hPDI、rEDIH、EAT13、NOVA4、Carbohydrate_pct；菌群使用旧流程 379 个 CLR-Z 物种。
- 原有分析文件与结果不改动；新运行产物保存在 `4New_cgm/outputs/<run_id>/`。
- 本轮为饮食→CGM及菌群→CGM的独立关联，并包含同样本比较和严格人群敏感性分析。桥接筛选、饮食→菌群重跑、中介及论文图表不是本轮入口自动执行的步骤。

## 复用规则

- 提取旧公共脚本的原样数值函数，存入本目录；不导入带服务器写出路径的旧入口，不依赖旧关联结果。
- Model 0 未调整；Model 2 复用旧协变量，hPDI 加饮酒；三个新增饮食暴露加总能量；Model 3 再加 BMI。
- 复用 OLS 和常规标准误；不因新数据分布改变估计方法。TAR180 零值集中和极端值等在说明中保留，结果作为沿用旧模型的首轮分析。
- 主人群排除 `exclude_diabetes_or_a10==1`，未知保留并计数；严格人群仅保留明确等于 0 者。
- 饮食完整协变量标志沿用旧 master；额外验证实际字段值。菌群按每个结局和模型所需协变量选完整样本，物种矩阵要求有限值。
- 模型以各自结局有效样本为准，不要求四个 CGM 同时完整，不要求七项饮食评分同时完整。
- 原四饮食 FDR 每个模型 16 次；EAT13/NOVA4 家族 8 次；碳水探索家族 4 次；另报告全部 28 次校正。TIR 为辅助解释，但计入预设四结局校正。
- 菌群每个结局 379 次 BH-FDR；另报告 4×379=1,516 次全局校正。失败模型保留状态，并用 p=1 作为校正占位保留计划检验规模，失败行本身不报告有效 p/q。
- 同样本比较：Model 0 与 Model 2 在 Model 2 样本上比较；Model 2 与 Model 3 在 Model 3 样本上比较，分别记录样本指纹。
