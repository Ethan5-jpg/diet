# Step19b Implementation Plan

Goal: 在独立可上传文件夹中完成冻结路径的只读方向整合。

Architecture: pandas读取原始模型与18f/18g/19a。以完整三元路径键一对一核对继承关系，内容唯一匹配选择模型；有歧义时停止并输出候选清单。数学方向与表型解释分离，输出全量表、重点表、图、来源哈希及简短终端摘要。

Tech Stack: Python 3.8+、numpy、pandas、matplotlib；unittest合成测试。无需导入旧脚本或访问参与者数据。

1. 静态核对18b/18c/18e2/18f/18g/19a，记录字段、路径、rEDIH及SDw状态。
2. 实现输入定位、严格布尔解析、重复/缺失键审计、继承值比较、预期计数检查及失败报告。
3. 接入原始a/b/效应/CI/N，检查乘积、药物协变量、数值有效性和跨模型符号。
4. 实现逐路径及逐菌/饮食/领域汇总，不平均相反方向，不计算新的FDR或健康分类。
5. 绘制4个三领域菌逐路径方向图、按饮食的间接效应图、三模型CI森林图；17个双领域菌保留完整表及图。
6. 测试正负组合、输入错配、模糊候选、无效值、近零、同短名不同菌、版本/字典错误和输入只读；端到端运行合成数据并检查图。
7. 编写中文上传运行说明和一键脚本；独立标记合成验证与服务器真实结果。

选择说明：不复制既有模型引擎，不依赖旧脚本的import（可能有目录写入副作用）；不按mtime选结果；不用短菌名连接。服务器路径从同级4New_cgm推导，支持显式路径覆盖。

执行授权来自本次用户“开始完成，把代码整理好上传运行”。此前计划已明确范围，无需重新选择实现方式。不创建git分支、不提交既有项目、不委派子代理。
