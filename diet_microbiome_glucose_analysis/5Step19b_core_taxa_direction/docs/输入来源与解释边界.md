## SDw疑点

14a、18g有 `cgm_sdw`，18g显示名为Interday SD；当前本地 `cgm论文新增17指标/config/outcomes.json`列出SDb、SDdm、SDhhmm、SDwsh，却未列出SDw。本地未找到该字段生成/清洗的完整链，因此不能单凭标签断定真实字段错误或正确。

[IGLU官方SD定义](https://irinagain.github.io/iglu/reference/sd_measures.html)（2026-09-20访问）将SDw定义为先计算各日SD，再取均值；SDdm为日均值之间的SD，SDb为相同时点跨天SD的均值。Step19b显示为 `SDw [source pending]`，保留冻结字段和领域，不改历史文件。

后续可在服务器定点检查最终CGM表来源、清洗代码和运行manifest。当前数值方向汇总不需要解释为日间或日内变化。
