## 4. 处理过程

### 4.1 固定旧队列，按完整连接键匹配

连接键为：

```text
participant_id + cohort + research_stage + array_index + connection_id
```

以旧最终表为左表进行一对一匹配。旧表必须一人一行，且属于 `cohort=10k`、`research_stage=00_00_visit`。不按行序拼接，也不只按 participant_id 匹配。

CSV 先按文本读取，保留 ID 前导零和旧单元格文本；仅在匹配副本中去除身份字段两侧空白，并将 array_index 规范为非负整数。缺身份字段、重复键、旧参与者重复、未匹配连接或 CSV 字段数错误均阻断运行。

### 4.2 对新比例进行合法性与分布审计

每个指标分别区分源缺失、非数值、无穷和超出 0–100 的数值。合法的 0 和 100 保留；非法值仅令该项 raw 缺失，不删除参与者、不补零。

审计报告有效/缺失人数、0/100 值人数与比例、均值、样本 SD、最小/最大值和 P1/P5/P25/P50/P75/P95/P99。缺失率分母为旧表总人数；0/100 比例分母为该指标合法有效人数。

### 4.3 检查三项比例互补及旧指标相关性

仅在三项合法原始比例均存在时检查：

```text
TAR180 + TBR70 + TIR70–180 ≈ 100
```

默认绝对容差为 **0.1 个百分点**；边界比较另容纳 `1e-12` 的浮点舍入误差，不修改原值。这是审计阈值，不是额外的数据清洗规则。

同时计算三个新比例与旧 mean、CV、TAR140、MAGE 的 raw/clean 版本 Spearman 相关，共 24 对。每对使用自身的有限完整样本重新计算平均并列秩；不以所有指标同时完整作为共同筛选条件。

### 4.4 依据审计分布确定新比例处理口径

TAR180 零值高度集中，TBR70 右偏，TIR 接近上界。因此本轮保留合法百分比，不将旧指标的最窄 95% 区间及 5SD/8SD 异常值规则直接应用到新比例。

新三项的统一规则是：

```text
source = 源 CSV 文本
raw    = 0–100 内有限原始百分比；非法值设为该项缺失
clean  = raw
```

不截尾、不作对数或其他变换，不用 epsilon 替代零标准差，也不将缺失填为零。合法范围内的高值继续保留。本次三项均没有非法值，所以各自 clean 与源百分比数值一致。

旧 MAGE 仍使用旧流程已经生成的 raw、clean、z，不按新增指标样本或任何后续子集重新计算。

### 4.5 每个新指标独立标准化

对每项 clean 的合法非缺失样本计算：

```text
z_i = (clean_i − mean(clean)) / sample_SD(clean)
sample_SD 使用 ddof=1
```

标准化人群为整个旧队列中该指标有效者。本次三项均为 7,493 人。一般情况下，若 N<2 或指标恒定，该项 Z 保持缺失并记录原因，不能制造有效 Z。

07 脚本读取指定审计 manifest，核验两份输入的 SHA256、06 脚本版本及内容指纹，并重新核对相同输入的审计摘要。输入变化时停止。输出前后检查旧列和旧行序，写出的 CSV 再读回核验旧单元格文本。

目前仍需在后续分析中明确：

1. **合法性不等于原始曲线验证。** TAR180、TBR70 的极端值虽然通过范围与互补检查，本轮没有逐条查看原始 CGM 曲线，不能据此排除测量问题。
2. **Z 不改变分布形状。** TAR180 的零值集中和三项比例的不对称仍然存在；标准化成功不代表已经验证某种关联模型。
3. **分析人数按结局另算。** 饮食、菌群和协变量合并后的 N 尚未确定，不应把四项同时完整作为默认入组条件。
4. **TIR 为辅助指标。** 三项比例具有互补关系，不能当作相互独立的信息。
5. **后续分析尚未开展。** 饮食—菌群—CGM 关联、敏感性分析、中介分析及多重检验范围不属于本次已完成内容；规则不根据后续关联显著性选择。

至此，本轮“复用旧 MAGE、独立补入三项比例并生成扩展表”的数据准备工作完成。
