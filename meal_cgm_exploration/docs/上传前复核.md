本页保留上一轮 2026.09.24.2 的验证记录；当前版本与新增修复见 [再次复核](再次复核_2026-09-24.md)。

日期：2026-09-24。版本：2026.09.24.2。

**结论：本包已准备好上传服务器，执行快速检查、餐次构建和既定的探索模型。** 本结论针对代码、运行衔接和文档；没有在服务器真实全量数据上运行，不能代替真实数据资格和结果核查。

## 本轮发现并修复的问题

1. **恢复运行遗漏新增 CGM 文件。** 原版只校验此前读取的文件。复核版比较完整文件集合，新增、删除或内容变化均要求重新运行；原先缺失的 NOVA 映射后来出现也必须重建餐次。
2. **拒绝重跑时可能改写配置快照。** 将恢复资格检查移到所有写入之前，拒绝操作时原配置、manifest、代码指纹及摘要保持不变。同一运行不能把已核实的时间语义改回未核实。
3. **部分配置值缺少边界检查。** 现在明确拒绝非整数分块大小、负图数、布尔值伪装数值、少于两个基线点等输入，避免长时间运行后才暴露问题。
4. **增加提前检查。** 新增 `--stage check`，检查 Python 依赖、全部 CGM 文件头、NOVA/协变量/菌群字段和唯一菌名匹配。不读取完整数据、不建立 SQLite。它分别报告构建条件和后续模型输入条件。
5. **增强数值与保存稳定性。** 固定效应计算改用 SVD，并对近似共线设计给出不可估计原因；JSON 状态文件采用原子替换；完整 CSV 读取拒绝多出字段造成的隐式行索引。
6. **补充移植性检查。** 支持含空格、中文和 URI 特殊字符的输出目录；缺少基础依赖时给出环境选择与安装提示；运行中检查来源文件的大小、修改时间和文件集合。

## 上传后顺序

在上传文件夹内、使用此前 HPP 分析的 Python 环境：

```bash
bash run_server.sh --data-root /home/ec2-user/Desktop/HPP/Data --stage check
bash run_server.sh --data-root /home/ec2-user/Desktop/HPP/Data --stage build
```

若服务器目录不同，调整 `--data-root`。check 的 PASS 只说明可以开始构建；SUMMARY 还会单独给出后续模型输入是否齐全。先读 build 生成的 SUMMARY.md 和餐次筛选表、示例图。

默认 `consumption_time_verified=false` 保持不变。根据平台字段说明确认实际食用时间并检查曲线后，再改为 true，用 build 的运行目录执行 analyze。没有替用户猜测这项科学事实。

最终上传整个 `meal_cgm_exploration` 文件夹即可，包括配置、代码、文档、测试和 PACKAGE_MANIFEST.json；不要上传 HPP/tmp 中的测试环境和模拟结果。
