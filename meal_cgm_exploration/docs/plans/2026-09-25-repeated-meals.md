# Repeated meals follow-up Implementation Plan

> Execution workflow: executing-plans. 用户已明确要求在当前文件夹完成本地实现与验证，无须再次询问是否开始；本目录不是 Git 仓库，直接保留现有源文件并新增模块。

**Goal:** 复用成功运行的餐次表，完成重复餐差异的参与者聚类置信区间、完整重复模板结构和按日期验证的餐前信息预测增益。

**Architecture:** 在 `followup/` 增加独立入口和模块，只读原运行、校验餐次与协变量指纹；新输出为 `outputs/repeated_<timestamp>/`。不修改旧 `hppmeal/` 或 `scripts/`，保证旧运行的代码指纹仍兼容。

**Tech Stack:** Python 3.8+，现有 numpy/pandas/scipy/matplotlib；不新增服务器依赖。

## 分析定义（看到当前截图后制定，属于后续探索性分析）

- 三个人群：全部可配对描述人群；原协变量和糖尿病/A10 primary 规则；strict 规则。不为重复性分析要求 NOVA 覆盖或 NOVA 个体内变化。
- 原配对：同人/队列/访视/食物签名，不同日期，时刻圆周差 ≤1 小时，按原算法贪心不重复使用餐次。重新从已验证餐次表推导并核对旧配对表。
- 四项单位均为 mg/dL 的指标：餐前基线、两小时平均绝对血糖、平均净增量、峰值升幅。所有配对指标在共同完整样本计算。
- 每个人是 bootstrap 抽样单位；每次抽中一个人就带入其全部配对，默认 1000 次、固定种子。报告配对加权的绝对差中位数/P90、平均有符号差，及“每人绝对差中位数的跨人平均”“每人有符号差均值的跨人平均”。人数不足 50 时只输出描述量，区间不估计。
- 完整模板保留同人同签名的全部有效餐，记录重复日期、餐次、时刻跨度、连接数量。模板结构与原时刻匹配配对属于不同口径，分别报告。当前版本不将混合模板的相关系数冒称 ICC，也不估计个人稳定性分数。
- 预测问题单独定义为“已知参与者、已见食物模板的较晚日期餐后两小时平均绝对血糖”。每个人/访视按有效日期排序，前约 70% 日期训练、其余测试，不拆同一天。至少 2 个训练日期和 1 个测试日期；模板至少 2 个不同训练日期才纳入预测，测试只保留训练已见模板。
- 三个嵌套预测：训练模板均值；模板均值+时刻/前餐间隔；再加入餐前基线与趋势。实际餐次时长在进食开始时未知，代码设计复核后明确排除。另给餐前基线直接延续的简单预测对照。模板内中心化、训练集标准化、固定 ridge 惩罚 10；不在测试集选特征或调参数。共同完整样本，所有模型评估同一批测试餐。
- primary 和 strict 各报告人数、日期及餐数流失；主要预测评价为每人平均绝对误差再跨人平均。使用测试参与者聚类 bootstrap 给出固定已训练模型的配对 MAE 改善区间；不称为重新训练整个流程的不确定性或新参与者验证。少于 50 名训练/测试参与者则明确 NOT_ESTIMATED。
- 保存训练/测试身份和逐餐预测到 private；汇总 CSV、图及 SUMMARY 不包含参与者 ID。区间均为后续探索性分析区间，不用于筛选显著结局。

## Task 1 — 输入与来源

Create `followup/run_repeated.py`, `followup/io_utils.py`。校验原 manifest 状态、时间解释标记、源码指纹、餐次 SHA256、协变量 SHA256。复用原协变量筛选函数，输出写到新运行。缺列、身份冲突、原配对不一致须失败。失败/中断保存状态；源运行不写锁或配置。

## Task 2 — 配对和完整模板

Create `followup/repeats.py`。数值重建、共同完整样本、三人群流量、模板分布、聚类 bootstrap 汇总。明确无配对/人数不足状态。测试零差异、整人重复抽样、同一人多模板、配对完整性及空集。

## Task 3 — 日期验证

Create `followup/prediction.py`。固定日期切分；模板训练支持检查；训练模板中心化和固定 ridge；统一测试集、MAE/RMSE及参与者等权误差、模型间误差差的聚类区间。测试未来结果不影响切分/模型/标准化，同一天不跨集、未见模板不外推、训练样本不足明确跳过。

## Task 4 — 汇报和入口

Create `followup/reporting.py`, `followup/README.md`, `followup/run_repeated.sh`, `followup/MANIFEST.json`。汇总图、中文摘要、完整运行与查看指令。新目录名不可覆盖；源文件在结束时再次校验。图仅显示总体分布和区间，不展示个人身份。启动脚本按用户要求放在 followup 内，整文件夹上传。

## Task 5 — 验证

Create `followup/tests/test_followup.py`。使用独立临时目录构建 SYNTHETIC 数据，覆盖 ≥50 人且每模板多个日期的端到端示例；同时测试无重复餐、无预测样本、指纹变更、错误配置、输出位置冲突和中断。运行新增与原 52 项测试、Python 3.8 AST、shell 语法和新文件清单校验。实际 Python 3.8 运行环境若不可用须明确仅完成语法兼容检查。
