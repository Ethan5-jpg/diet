# 日期分离的餐反应—CGM衔接分析

版本：2026.09.28.2。上传目录：**整个 `date_split_bridge` 文件夹**。

上一轮 `response_followup` 已完成交互系数换算和日期分离可行性检查，但没有拟合日期分离的新关联。本包补上这一步：用前半段日期的个人餐反应，关联后半段日期重新计算的CGM指标，检查去除共享读数后关联是否仍存在。

## 上传与运行

把本文件所在的 `date_split_bridge` 文件夹放进服务器的 `meal_cgm_exploration/`，与 `response_followup/`、`nutrition_bridge/`、`outputs/` 同级。保留原有文件夹和结果。只需上传这个新文件夹，不必上传 `research_records`、`docs` 或本地模拟结果。

在服务器原来的 `(pheno)` 环境、`meal_cgm_exploration` 目录中运行：

```bash
bash date_split_bridge/run_date_split_bridge.sh --followup-run outputs/response_followup_20260927T155611_920880Z --data-root ..
```

完成后，只显示3份关键摘要：

```bash
python3 date_split_bridge/run_analysis.py --show latest --brief
```

**只回传这3份摘要的截图即可。** 无需再发几十页明细。如果一屏放不下，可分别用 `--show latest --page 1`、`--page 2`、`--page 3`；不要同时加 `--brief`。如果运行报错，回传报错末尾即可，先不要改数据或放宽检查。`latest` 如指向失败/未完成运行会明确报错，不会偷偷显示更早结果。

本版会在检查输入前登记运行；即使缺少前置目录或来源JSON损坏，也会留下FAILED记录，阻止 `latest` 显示上次成功结果。输出目录本身无效或不可写时无法登记，请以当前启动报错为准，只在完整运行成功后执行查看命令。

`--data-root ..` 指原项目的上一级数据目录；这是已有运行所使用的目录结构。若项目位置不同，传入实际包含原分析输入的数据根目录。脚本只支持已有完整 `response_followup` v2026.09.27.2 结果，逐级核对nutrition、quality、餐数据和CGM缓存来源。缺少任何来源时停止，不会自行换一批样本。

要求Python>=3.8和原分析环境已有的numpy/pandas/scipy等依赖。无需安装新库；可用 `HPP_MEAL_PYTHON=/path/to/python` 指定解释器。首次仅读取输入检查可加 `--stage check`；正式计算仍须运行上面的完整命令。检查运行没有研究结果摘要。

## 这次会回答什么

1. 前窗个人净增量、峰值、正增量，与后窗Mean、CV、SDw、MODD15的关联是否仍存在？原样本与joint共24项主分析，全部展示。
2. 在同一批人、同一前窗X、同一协变量和尺度下，后窗关联与全期新指标关联相差多少？提供24项全期对照及24项配对差值，明确列为次要分析。
3. 新指标带来多少额外样本损失，与旧全期指标的排序是否大致一致？这些是方法和选择诊断，不是独立验证。

本次不再拟合饮食评分交互，也不把上轮小幅D值解释为临床收益。负的“后窗−全期”系数差并不证明旧关联全部来自共享读数；窗口长度、测量可靠性及时间变化也会影响差异。

## 固定定义与解释边界

所有规则在读取真实新结果前固定于 `CONTRACT.json` 和 `PLAN.md`。

- 使用上轮同一连接的日历中点、同一前窗餐成员和原背景协变量；核对14项旧可行性人数。前窗餐实际使用的CGM读数严格早于切分点，后窗插值支撑读数不早于切分点。
- 新CGM定义：已有完整、单连接、原始15分钟覆盖率>=90%的本地日，再建立日内15分钟网格；相邻支撑读数间隔<=45分钟，不跨日借值、不外推、不跳过显式无效读数。网格有限值覆盖率也须>=90%，至少3个合格日。
- Mean为合格网格值均值；CV为总体网格样本SD/Mean×100；SDw为各日样本SD的等权均值。前两者按网格点等权，SDw按日等权；使用ddof=1。
- **MODD15是本包明确命名的新操作定义**：真正相邻的非夏令时变更日，同一15分钟钟点的血糖绝对差均值；每对日>=48个配对格，至少2对。不跨缺失日连配，不把上一轮可行性代理值当MODD。23/25小时日仍可用于其他3项指标。
- 本地没有找到旧iglu导出的完整生成合同，因此**不声称新窗口指标精确复现旧iglu**。旧全期Z只用于与新全期指标的相关诊断，不当后窗结局、不把其系数直接相减。具体公式来源与自定义限制见 `PLAN.md`。
- 每人一行、等权OLS，沿用HC3稳健标准误和t区间。至少50人、30残差自由度；不能估计的规格保留及说明原因。主分析24项共同BH，另两类次要结果各自固定24项BH；逐项95%区间不是多重校正区间。
- 每个X/Y以原样本完整配对队列的前窗X样本SD和全期新Y样本SD为参考，两样本及3类模型共用。表中β为参考Y的SD/参考X的SD；原单位系数和尺度另存。全期对照含后窗，可能含前窗餐读数。配对差值通过对同人 `(后窗Y−全期Y)` 拟合相同设计计算，不把两组独立标准误相加。
- 原样本与joint重叠；这些是内部关联和敏感性分析，不是独立人群复现、因果效应或预测性能验证。
