# 第 5 步：计算完整 AMED 八项评分

## 目的

使用 `Data/diet_deal/scripts/amed/05_calculate_amed_scores.py` 读取第 4 步生成的参与者级 AMED 成分摄入量，并通过 `participant_id + cohort` 与 `population.csv` 一对一匹配性别，一次完成七项食物分、性别特异酒精分和 0–8 分 AMED 总分。原先因缺少性别而单独执行的第 6 步已合并到本步骤。

## 计分方法

1. 水果、蔬菜、全谷物、坚果、豆类和鱼类：平均每日摄入量高于队列中位数记 1 分，否则记 0 分。
2. 红肉和加工肉：平均每日摄入量低于或等于队列中位数记 1 分，否则记 0 分。
3. 酒精：`sex = 0` 对应女性，5–15 g/day（含边界）记 1 分；`sex = 1` 对应男性，10–25 g/day（含边界）记 1 分；其余完整酒精记录记 0 分。
4. 酒精记录不完整的参与者保留缺失，不将其错误地记为 0 分。
5. 七项食物分与酒精分均完整时，才计算 `amed_total_score_0_8`。

## 输出文件

1. `amed_participant_scores.csv`：参与者性别、七项摄入量、七项食物分、酒精分、0–7 分食物小计、0–8 分完整 AMED 总分及完整性标记。
2. `amed_food_component_thresholds.csv`：七项食物成分的队列中位数、比较方向、并列中位数数量和得分人数。
3. `amed_score_qc.csv`：性别匹配、酒精完整性、各分项阈值和 AMED 总分分布等质量控制指标。
